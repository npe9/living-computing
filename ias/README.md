# IAS Machine (1952)

John von Neumann, Julian Bigelow, Institute for Advanced Study, Princeton. The archetypal "von Neumann architecture": 40-bit words, two 20-bit instructions per word, 1024-word Williams-tube store, bit-parallel asynchronous arithmetic. Copied widely (JOHNNIAC, MANIAC, ILLIAC, ORDVAC, IBM 701 lineage).

Bluespec implementation: `bsv/` (not started).

Sources: Burks, Goldstine, von Neumann, *Preliminary Discussion of the Logical Design of an Electronic Computing Instrument* (1946); Dyson, *Turing's Cathedral*.
