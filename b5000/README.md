# Burroughs B5000 (1961)

Bob Barton, Burroughs. Stack architecture designed for ALGOL; descriptors, tagged words (48-bit + flag), hardware-supported segmented virtual memory, multiprogramming with MCP (Master Control Program). Lineage: B5500, B6500/6700, Unisys ClearPath.

Bluespec implementation: `bsv/` (not started).

Sources: *Burroughs B5000 Reference Manual* (1961); Barton, "A New Approach to the Functional Design of a Digital Computer" (WJCC 1961).
