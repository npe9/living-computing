# except for *+"; - otherwise), Printed page.
# The page's own words on the forms (p.47): "A specific title for each
# mnemonic is not given in cases where the mnemonic is derived from the basic
# operation by changing the sign and absolute modifiers."
# Transcription notes:
#  - p.49 prints the VFL Multiply Factor and Add pair as "*+" and "*N"; the
#    second is written *N+ here (its symbolic description is -m.($FT)+a, and
#    p.44 lists V *N+ "Multiply Negative and Add").  Its note 1: "Write: *I+
#    and *NI+ for an immediate operand"; those two rows follow it, marked -
#    because they are already the immediate spelling.
#  - p.50 prints the connectives as Cx1x2x3x4, CMx1x2x3x4, CTx1x2x3x4 and the
#    immediates CIx1x2x3x4, CTIx1x2x3x4: written C####, CM####, CT####,
#    CI####, CTI####.  "LF = C0011", "SF = CM0101".
#  - p.51 prints "CBRZ or CBZR"; both rows are here.  Its note: "the value
#    field of J may be modified by placing +, -, or H after the above
#    mnemonics" (CB+ CB- CBH are its example; the suffixed forms are not
#    rows here).
#  - p.51 BB/BZB "may have a suffix, Z, 1, or N"; the eight forms it prints
#    are rows.  BIND and BZIND: "IND" is replaced by an indicator mnemonic
#    (p.52 lists them) and a Z suffix may follow; MIBA's family, not rows.
#  - p.53 "LOC(SEOP) RD(SEOP) W(SEOP) REL(SEOP) CTL(SEOP) SU(SEOP)" are
#    written LOCSEOP etc. (the newsletter's own spelling of the same form).
