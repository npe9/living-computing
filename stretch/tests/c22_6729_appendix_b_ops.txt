# OWN LIST: the strongest witness of what its table of operations holds.
# Its footnotes, verbatim:
#   1 Additional is used in the sense that the instructions and pseudo-ops are
#     not specified in the IBM-7030 Reference Manual.
#   2 An operation mnemonic cannot exceed 8 characters in length.
#   3 [on "Pseudo-Ops"] These pseudo-ops are in each of STRAP II's three-digit
#     select pseudo-op tables.
#   4 [on CNOP and EXT] With the exception of the EXT and CNOP instructions,
#     STRAP II considers an instruction to be a pseudo-op if it does not
#     produce binary output.
# Columns: Group, Mnemonic, Name (- where none is printed).  Groups as printed:
# PSEUDO, GENERAL, MCP, IO ("Input-Output Instructions: OP, A7(I) where A7(I)
# represents a channel address and the unit affected is the last unit
# selected by an LOC instruction"), IOSEOP (the indented rows), SECONDARY.
# Printed "PUNSYN(or PUNSYM)" is two rows here.  The page prints the pseudo-ops
# and the I-O instructions in two columns; read down the left column, then the
