# IBM 7090 (1959)

Transistorized 709. 36-bit words, 32K core, 2.18 μs cycle, 3 (7 on 7094) index registers, data channels. The standard large scientific machine of the early 1960s (Mercury, Gemini, CTSS).

Bluespec implementation: `bsv/` (not started).

See [`plan.md`](plan.md) for the staged reproduction plan and
[`docs/README.md`](docs/README.md) for the local primary-source inventory.

Sources: *IBM 7090 Data Processing System Reference Manual* (A22-6528).
