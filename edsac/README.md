# EDSAC (1949)

Maurice Wilkes, Cambridge. First practical stored-program computer in regular service. Mercury delay-line store, 512 (later 1024) × 17-bit short words (35-bit long), serial arithmetic, 18-instruction order code, initial orders (bootstrap) on uniselectors. Origin of subroutine libraries (Wheeler jump).

Bluespec implementation: `bsv/` (not started).

Sources: Wilkes, Wheeler, Gill, *The Preparation of Programs for an Electronic Digital Computer* (1951); Campbell-Kelly's EDSAC tutorial guide.
