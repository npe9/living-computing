# DEC VAX-11/780 (1977)

Bill Strecker et al., DEC. 32-bit "Virtual Address eXtension" of the PDP-11: 16 GPRs, orthogonal CISC instruction set with up to 6 operands, paged virtual memory with 4 access modes, microcoded, the 1-MIPS yardstick.

Bluespec implementation: `bsv/` (not started).

Sources: *VAX Architecture Reference Manual* (Digital Press); *VAX-11/780 Hardware Handbook*.
