⑤ next-pattern arrows, ⑥ fill pattern.
The figure window's figures fall into three kinds: ① line figures, ② filled figures, ③ characters.
Line figures use line type (②) and width (①). Filled figures use the border flag (④) and pattern (⑥).
Clicking ⑤ shows the next pattern candidates. The logical operation is ③: set, reset,
xor(exclusive_or) and color (colour selection). color opens Fig. 2-7:

       |■ | 0 | 2 | 4 |   |   |   ① current colour   ② registered colours   (カラー表示ウインドウ)
       |  | 1 | 3 | 5 |   |   |
       +--+---+---+---+---+---+
       | →  ←  add  change  exit |   (カラーメニュー)
