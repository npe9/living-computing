 (2) スクロール機能 (scroll): via →, ←, ↑, ↓ or show. In show, one left click outlines the current region
     with a rectangle; a second left click frees the rectangle to move; a click places it.
 (3) グリッド表示 (grid): 'grid' opens Fig. 2-4, which sets grid on/off (grid), grid size (size) and the
     mouse input unit (unit). Grid size is in dots, 1-99. With unit=grid a mouse input snaps to the
     upper-left of the four surrounding grid points.
