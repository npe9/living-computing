# Fixed-point search for SIMPOS, its subsystems, its manuals and Common ESP (2026-11-24)

The third search of the day, after `web_search_2026-11-24.md`, `web_search2_2026-11-24.md` and
`sweep_2026-11-24.md`. Those three each ran once. This one ran in **rounds**. Each round followed
every lead the previous round produced, in the held material and on the web. It stopped at a
**fixed point**: a round in which every new lead had been followed and none gave a new source or a
new fact.

All accesses were on 2026-11-24. Nobody was contacted, nothing was bought, no form was submitted,
no terms were accepted and no bot challenge was bypassed. "Opened" means the text or page images
were read. "Located" means only a catalogue or search record was seen.

> **No SIMPOS or CESP code, binary, tape image or software archive was found** in any round, held
> or on the web. Nothing is listed for the owner to fetch. No new SIMPOS method body (HELD-SOURCE)
> turned up; the only held SIMPOS source is still what `finds.md` §1-3 and §5a list.

## 1. Method

**The lead ledger.** It was seeded from everything learned so far: `../../psi_acquisition.md`
§1-§13, `../../archive_search_notes.md`, `../source_notes.md`, this directory's three earlier
records and its specs, `../trtm_table.tsv`, `../printed/coverage.tsv` and
`../../nonlocal/lit/SOURCES.tsv`. Every person, title, organisation, version, file name, path
stamp, place and "not searched" item became a lead with a status.

**Held material, each round.** The held archives under `pim/docs/nonlocal/` were unpacked again into
scratch:
- rounds 1-4: the 312 `.tar.Z`/`.tgz`/`.tar.gz` archives, one level deep (1.0 GB);
- from round 5 on, recursively, by magic bytes: 124 more inner archives (inner tars, `.Z` and `.gz`
  files inside archives) and the 27 single compressed files (`manuals/pimos/*.Z`, the FGCS'94 `.ps.gz`
  files, three contract-research `.zip`). In all, 1.3 GB and 209,830 files.
- This is fewer than the second sweep's 475. That sweep also unpacked v7 tars without the `ustar`
  magic, shars and uuencoded files.

The tree was searched three ways:
- with regexes on raw bytes;
- with a Japanese-decoding grep (ISO-2022-JP, EUC-JP, Shift-JIS, UTF-8) for the ledger's names
  and titles;
- with a new usage census of the ESP code no earlier pass had mined (`tools/fe_census.py`). From
  round 5 it selects ESP by content as well as by suffix: a file counts if its name ends in `.esp`
  or it defines a class. The IFS keeps ESP under `.v32`, `.wkm`, `.talk`, `.grape`, `.slv`, `.ctl`,
  `.esp.1` and other suffixes. The rerun added pax (15 keys).

**Web, round 1.** Three delegated searches ran in parallel: people; manual and book titles;
organisations, places, code and version strings. Their reports were checked against the files
here, and the sources they opened were re-fetched and read for the facts used below.

**Web, rounds 2-4.** These were run directly, with these tools:
- CiNii Research's OpenSearch JSON (its record pages answer HTTP 202, a JavaScript gate);
- the IPSJ repository's record API and file links;
- NDL Search OpenSearch and the NDL Digital item API;
- KAKEN;
- general web search.

**Reading, and how each fact was checked.** Image-only IPSJ PDFs were rendered at 300 dpi and
OCR'd (tesseract jpn+eng). Each fact is marked by how it was checked:
- **page image read here**: IPSJ 113884 p.1, 115299 p.2, 119496 p.1, 120508 p.2, 114360 p.1;
- **OCR only**, which garbles some characters (it printed "STMPOS" and "2.OR"):
  - IPSJ 113884's reference list, also read by the delegated search;
  - IPSJ 114360 p.2 (the pool and the windows);
  - IPSJ 4378's references;
  - the RLS and EXTKERNEL papers;
- **reported by a delegated search and not re-opened here**: every NDL Digital item. These are the
  manual numbers MP1002-1 and MP3003-2, 「小型化PSI ESP説明書」 (1988), the 通産省公報
  registrations, the bit 1990 per-part authors and pages, 「CESP言語2.0版」 (1994), the
  "SIMPOS Version 5.1" screen in ETL report 954, and the 機械振興 and AI白書 items. The NDL Digital
  API refused anonymous queries here. Only the bit series itself was confirmed, through NDL Search
  OpenSearch: twelve records of 「ESPerへの道-論理型オブジェクト指向言語 ESP」 (1990) and the
  issues 22(1)-22(11);
- **held source line read here**: every held-material fact.
