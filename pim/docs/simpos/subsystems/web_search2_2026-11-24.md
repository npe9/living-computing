# Second web search for SIMPOS's window system, Librarian, shell and Common ESP (2026-11-24)

A delegated, targeted follow-up to `web_search_2026-11-24.md` (the first search). It went to the
places the first did not reach (its "Not searched" list) and followed the leads it left: Common ESP
(CESP), the 1987 I/O manual, library holdings, and the people. All accesses were on 2026-11-24.
Nobody was contacted and nothing was bought. "Opened" means the text or page images were read;
"located" means only a catalogue or search record was seen. Page numbers are printed page numbers.

> **No SIMPOS or CESP code, binary or tape image was found anywhere.** No software archive was
> located, so none is listed for the owner. The CESP V3.3 release notice (below) says AIR shipped
> **object code** on tape to sites that signed a research-use contract; the one user report of
> "source codes" (comp.lang.prolog, 1992) is contradicted by AIR's own notice, unless it meant the
> class library's ESP source (unknown).

## Strongest new finds

1. **SIMPOS 2.52's size, from a study of its whole source** (IPSJ 51390, opened, new, downloaded).
   青柳龍也 (東大工学部), 「SIMPOSおよびSmalltalkの名前づけ」, 知識工学と人工知能 51-7
   (1987-03-12), pp.49-55. https://ipsj.ixsq.nii.ac.jp/records/51390
   - "SIMPOS version 2.52" (p.50) has **1,450 system classes** and **15,064 methods** (9,268 if
     the four implicit methods `new`, `class_name`, `super`, `class_object` are counted once per
     system), with **4,412 distinct method names** (Table 1, p.51). Its whole source is about
     750,000 words (p.52). Only principal predicates were counted, not before/after demons or
     local predicates.
   - Table 3 (p.52), the commonest words in class names, with counts: as 177, with 146, window 143,
     file 139, tap 77, menu 69, editor 65, buffer 49, error 47, manipulator 47, message 45, handler
     42, input 42, library 39, command 35, mail 35, character 30, list 30, font 28, table 28. In
     method names: get 1,455, set 1,085, create 488, do 255, file 213, read 207, to 199, size 192,
     write 190, string 188, add 180, command 157, remove 156, code 146, delete 146, type 145,
     window 145, initiate 143, status 143, message 142.
   - Mean name length: class 16.6 characters (max 47), method 10.0 (max 39) (Table 5). Example
     method names (Table 10): `create`, `initiate`, `cut_off`, `get_status`, `class_name`, `goal`,
     `size`, `command`, `new`, `super`, `in`, `empty`.
   - It cites a manual not otherwise recorded: **「SIMPOS総合説明書（第一版）」, ICOT, 1986**.
   - The author's group at Tokyo (田中英彦 lab) had the SIMPOS 2.52 source to analyse in 1986-87.
     Its companion, IPSJ 114021 (33rd convention 5D-4, 1986, opened, not downloaded), planned
     to build NameMaster into the PSI's editor and Librarian.
2. **The CESP V3.3 release notice** (opened). 佐竹 Norio Satake, AIR, "CESP(V3.3) release",
   fj.ai / fj.comp.oops / fj.lang.prolog, 6 Apr 1992, Message-ID `<102@airgw.air.JUNET>`. Read
   in the Internet Archive's `usenet-fj` item (file `fj.lang.prolog.mbox.zip`, 239,271 bytes;
   https://archive.org/details/usenet-fj). It says:
   - CESP had been distributed since **November 1990** and was used at **about 200 sites**.
   - V3.3 is distributed **free, for research use only, under a contract**; the user sends a 1/4"
     cartridge (CMT) and receives **CESP object code** for Sun-4 (SPARC); the Sun-3 version is
     withdrawn. Environment: SunOS 4.0.3-4.1.2, 16 MB, 90 MB disk, GNU Emacs environment, X11R4
     window interface (Japanese needs Xmw and Wnn).
   - V3.3 adds: a fuller **Librarian**, image processing and affine transforms in the **window
     functions**, a fuller pool, dynamic atom table, class `builtin`, interrupt checks.
   - **Manuals (seven):** CESP言語（3版）, CESP使用の手引（3版）, CESPライブラリI（3版）,
     CESPライブラリII（3版）, CESPプログラミングI, CESPプログラミングII, CESPプログラミング事例.
   - Contact: (株)AI言語研究所, 東京都港区芝3-15-15 桜井ビル3F, 研究管理課長 畑邦夫,
     cesp-request@air.co.jp, fax 03-3456-4418; a mailing list cesp-ml@air.co.jp from 1 April 1992.
3. **By March 1994 CESP was sold by Mitsubishi Electric Computer Systems (Tokyo).** The held
   Japanese page `nonlocal/ifs/_catalogue/INFO/cesp-J.html` (read here; the English page is held
   too) says CESP was developed by AIR and **sold by 三菱電機東部コンピュータシステム(株)**,
   応用システム第二部SP推進グループ, 横浜市戸塚区川上町87-1, as of March 1994 (CESP 3.3, X11R5).
   **That is the company of 児玉泰子 and 藤本誠司, the SIMPOS Librarian customisation authors**
   (IPSJ 118681), and of the SIMPOS volume-compaction paper (IPSJ 118591). One company held both
   SIMPOS Librarian work and CESP.
4. **Chikayama on SIMPOS's size** (fj.comp.misc, 3 Jul 1987, `<467@icot.JUNET>`, opened, in the
   Internet Archive item `ancientfj-2004-10-18`, `fj.comp.misc.tgz`): SIMPOS is "about 270,000
   lines", and the ESP written in all is "nearly 300,000 lines". The thread (ETL's 加藤俊和)
   complains that the PSI manuals were very hard to read.
5. **Pmacs could show one buffer in several windows** (fj.sources.d, 25 Aug 1988,
   `<361@enterprise.mtl.u-tokyo.JUNET>`, opened): "SIMPOS/PMACS みたいに、buffer を共有した、
   Emacs Window を複数開けないかな". A user's remark, not documentation.

## For the specs

New facts for `window.md`, `librarian.md`, `shell.md`, `gaps.md` and `finds.md` (this file does
not edit them):

- **Scale (all three):** SIMPOS 2.52 had 1,450 system classes, 15,064 methods and 4,412 distinct
  method names (IPSJ 51390, Table 1). A reconstruction's coverage can be stated against these.
  "window" occurs in 143 class names, "menu" 69, "buffer" 49, "manipulator" 47, "library" 39,
  "command" 35, "tap" 77 (Table 3). Chikayama (1987): about 270,000 lines.
- **Manual titles to add to the wanted list:** 「SIMPOS総合説明書（第一版）」 (ICOT 1986, cited by
  IPSJ 51390). No holding library found (CiNii Books: 0).
- **Window / Pmacs:** Pmacs could open several windows on one shared buffer (1988 user remark).
  The PSI/UX ran SIMPOS and UNIX side by side on X windows (Giho 1991-03, held, product page:
  「Xウィンドウ上では、SIMPOSとUNIXが並行動作します」).
- **Librarian (CESP):** CESP 3.3's release lists a fuller Librarian; the CESP manuals are
  CESPライブラリI/II (3rd ed.), which would describe CESP's re-implementation of the SIMPOS window
  library.
- **CESP window system:** CESP 3.3 window functions gained image processing and affine transforms;
  the X11R4 interface needs Xmw and Wnn for Japanese (1992); X11R5 by 1994.
- **ESP vs CESP (cesp-J.html, held):** "the emacs_window in CESP is different from the
  pmacs_window in ESP": so `pmacs_window` is a SIMPOS class name (check against the census).
