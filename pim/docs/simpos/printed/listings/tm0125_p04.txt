== Figure 1. System structure around the Window System  (block diagram, rendered as text)

   [Coordinator]        (Process) - - - (Process)
         |                  |   \           |   \
         |                  |    `----------+----+--------.
   +--------------------------------------------+         |
   |              Window Subsystem              |----[Kana-Kanji      ]
   +--------------------------------------------+----[Translation     ]
         |                  |              |      |  [Module          ]
   [Bitmap Display    ] [Mouse   ]   [Keyboard          ]
   [Handler           ] [Handler ]   [Handler           ]

   Reading of the line drawing (by eye): Coordinator and each Process connect down to the
   Window Subsystem; lines from the Processes also run past the Window Subsystem's right
   edge to the Kana-Kanji Translation Module and down to the Keyboard Handler (the lines
   cross with jump-overs). The Window Subsystem connects down to the three handlers.
   Exact attachment points of the crossing lines are NOT certain at this resolution.
