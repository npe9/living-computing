Task list (p4, printed): (1) SC, RC -- TCP/IP protocol tasks; SC output side, RC input side.
(2) SI, SO, SA -- take user requests from HLIF and pass them to SC/RC; SI input, SO output, SA asynchronous;
one SO/SI/SA task per socket ("a socket is a virtual communication endpoint"); 32 of each.
(3) HLIF -- interface between the C bus and the CI, CO, SI, SO, SA tasks; parses the serial data stream from
the C bus and sends messages to the task concerned. (4) MAC -- LAN control (10 Mbps, CSMA/CD, IEEE 802.3).
(5) モニタ -- own multitask monitor: task switching, inter-task messages, memory management.
(TRANSLATION, mine.) CI/CO are drawn but not described.
