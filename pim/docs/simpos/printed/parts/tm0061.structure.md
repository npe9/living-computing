# TM-061 — 「逐次型推論マシンPSIのオペレーティング・システム」 (服部, 黒川, 坂井, 辻, 近山, 高木, 横井; May 1984, 11 PDF pp)

This is the Japanese version of TM-065. It is one month earlier and has the same structure. Every page was read by eye. PDF page = folio + 1. Listings: `tm0061_p06.txt` (Fig 3.1), `tm0061_p06.esp`, `tm0061_p07.esp`, `tm0061_p08.esp`. Differences from TM-065 are in `A/listings/VARIANTS_tm0061_vs_tm0065.txt`.

## Printed in enough detail to reimplement
These are the same classes as TM-065, with hyphenated identifiers: file, binary-file, bare-window, with-border, with-label and window-with-border-and-label. The ESP syntax is on PDF p4, in Japanese.

The page also states something TM-065 leaves implicit: 自クラスの位置も指定できる ("the position of the class itself can also be specified"; TRANSLATION). This is the meaning of `*` in the nature list (PDF p4, folio 3).

## Sketched only
- **Fig 3.1** (PDF p6). It adds トランスデューサ and uses ライブラリアン for Library. It has no Printer and no Timer.
- **Elementary, hardware and device classes** (PDF p5). Named only.
- **The real file natures** appear as a listing comment (PDF p6).
