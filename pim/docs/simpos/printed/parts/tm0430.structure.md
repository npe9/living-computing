# TM-430 (bundle; table date 88.01): paper "PSIにおけるTCP/IP機能の実現方式" (Hasegawa, Tatara, Mitsubishi / ICOT), PDF p3-4
Status in trtm_table.tsv: "fetched 2026-11-23" (not "held"); added in the final pass because it is the only report

- p3 (eyed; printed: 「ソフトウェアとしては、ftp(ファイル転送プログラム)とtelnet(リモート端末プログラム)をSIMPOSの拡張機能として試作するとともにその«…»のハードウェアの整備を行っている。」): TCP/IP added "to connect with a wider range of computer systems"; **ftp (file transfer program) and telnet
  (remote terminal program) are being prototyped as extensions of SIMPOS** ("SIMPOSの拡張機能として試作"); the paper
  covers the transport layer and below only.
- Design (p3): TCP/IP implemented as SIMPOS-extension software plus firmware, with the function split tuned for speed.
- Software (p3): (a) socket interface -- the user interface; "provides each TCP/IP function in the form of methods";
  a user can use 32 sockets, connection and connectionless; includes routing for reaching other LANs via gateways and
  a network-usage display. (b) CIOP handler -- sends/receives data to the LAN controller through the CIOP.
- Hardware (p3): existing CIOP and XVLAN boards, joined by an internal "C bus".
- Firmware (p4, Fig. 2, listings/tm0430_p04.txt): tasks SC/RC (TCP/IP), SI/SO/SA (per socket, 32 each), HLIF, MAC
  (82586, IEEE 802.3), monitor. Status: prototype nearly complete on PSI, under evaluation.
- SKETCHED: no socket class name, no method names, no ftp/telnet design. TR-524 p2-3 says TCP/IP was available
  from spring 1989.
