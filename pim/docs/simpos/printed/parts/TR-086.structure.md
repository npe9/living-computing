# TR-086 Sequential Inference Machine: SIM -- Progress Report (Uchida et al., Oct 1984). 13 PDF pages, OCR read; no listing or SIMPOS figure.

## Layering (p4) -- differs from TR-057/TR-087
- "SIM's total software system is named SIMPOS". Two parts: "Kernel operating system" = managing processor, memory and I/O devices; "formulating abstract resources such as process, pool, stream"; and "sophisticated I/O functions such as a multi-window system, file system and network system". "Programming system" = language processors for ESP, editor, debugger, coordinator. I.e. here the window/file/network systems sit inside the "kernel operating system", whereas TR-057 p5 has kernel / supervisor / I/O media as three layers. p10 also calls the window subsystem "the most complex subsystem in the kernel operating system".

## KL0 additions motivated by SIMPOS (p4)
- multi-level cut; bind-hook and exception-hook operations ("like the freeze operation of Prolog-II"); strings and vectors (vectors "often used to implement a variety of operating system control tables"); special built-ins to access hardware registers, used "mainly in the kernel operating system, namely, the memory manager and the device handlers".

## History and boot/IPL (p8-10)
- SIMPOS functional spec end of March 1983 (<10 ICOT members); ESP spec first draft July 1983; team ~30 from June 1983; ESP compiler and simulator on DEC 2060 August 1983; detailed SIMPOS spec (class modules and interface specifications) first draft end of November 1983.
- SVP = PDP-11/23 "PSI's supervisor processor", connected to the DEC 2060 via DECnet, used for hardware/firmware debugging and "later used for debugging the kernel parts of SIMPOS, for example, an IPL (initial program loading) program" (p8).
- IPL: design and coding started around end of 1983; "The IPL program included many modules of the kernel operating system and also run-time support routines of ESP"; debugging completed end of April 1984 (p10). SKETCHED: no format or module list.
- Window subsystem operational July 1984; firmware support added later (clause indexing; planned built-ins for method call and slot access) (p10). SIMPOS size "approaching 90K ESP lines", team >40 incl. 6 ICOT (p10-11).

## Hardware facts relevant to the OS (p11)
- 40-bit words (8-bit tag + 32 data); main memory divided into 256 logically independent areas, each usable as stack or heap, demand-based page assignment; up to 63 hardware-supported processes; IEEE 796 I/O bus; 10 Mbps CSMA/CD LAN (ICOT-Net); 16M words max memory; 30K LIPS.
## Profile (p12)
- All characters 16 bits in SIMPOS; network subsystem gives access to remote processes and files; library module includes ESP compiler and linker.
