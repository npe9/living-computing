# TM-181 「SIMPOSにおけるプログラミング環境」(石橋弘義 他; 昭和61年 (1986) joint convention paper). 5 PDF pages, Japanese; read by eye at 100/400/600 dpi. Overlaps TM-143 heavily (same layer list and figure on p2). New material only; TRANSLATION mine.

- p3: standard-io-window: its definition lists 10 inherited classes, but the full set after inheritance is 40 classes, 121 slots (1 class slot), 527 methods (14 class methods). Shows how deep the window class lattice is. Object paragraph: "SIMPOS provides window / file / buffer (memory) as standard I/O" behind one output protocol.
- p3: OO drawbacks stated: method calls dynamically bound so methods cost more than local predicates ("ESP style: use local predicates for internal processing"); inheritance analysis static at registration, so superclass changes force re-analysis of subclasses; risk of accidental redefinition of inherited slots/methods.
- p3 (7): SIMPOS 2.1 size: ~200,000 source lines incl. comments and blanks; 1,448 classes; ~17,600 defined predicates of which ~8,380 local. Everything from device handlers and memory/process management to the programming system in ESP.
- p3 system menu screenshot (listings/TM-181_p03_system_menu.txt): Experts debugger, pmacs, librarian, file_manipulator, spooler, font_editor, edips; MEDIA SYSTEMS user process list, window manipulator, network, shell, whiteboard, kanakan initiate, garbage collection, login, shut down. (Garbage collection is a user-invocable media-system item: INFERENCE that GC can be triggered from the menu.)
- p4 (5) editors: Pmacs (Emacs-like, from TM-143/181 text) and Edips (structure editor). (6) librarian, (7) debugger/interpreter, (8) window manipulator, (9) file manipulator: hierarchical files, path ">sys>user>me>file_name"-style names, multiprocess sharing/exclusive control; menu functions: logical names for paths, make directory, list file names, delete/copy, disk<->floppy copy. Screenshot file names show the form name.type.version (e.g. my_window.esp.5, login.cmd.2, debugger.init.1).
- p5 (10) network: Ethernet LAN; file transfer PSI-PSI and PSI-VAX; via a gateway to NTT DDX to reach remote LANs; talk, e-mail, remote file access, remote printer output; PSI with large disks as file server, PSI with laser printer as print server. SKETCHED.
- p5 (11) Japanese I/O: JIS 16-bit internal code; kana-kanji conversion. (12) font editor. (13) situation: exception handling uniform from system to user programs; same exception handled differently by situation; on an error a menu of applicable recovery methods is shown.
