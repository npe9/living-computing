# TM-065 — "An Operating System for Sequential Inference Machine PSI" (Hattori, Kurokawa, Sakai, Tsuji, Chikayama, Takagi, Yokoi; June 1984, 19 PDF pp)

Every page was read by eye. PDF page = printed folio + 2. Listings: `A/listings/tm0065_p03.txt` (Fig 1.1), `tm0065_p06.txt` (Fig 2.1), `tm0065_p11.txt` (Fig 3.1), `tm0065_p12.esp`, `tm0065_p13.esp`, `tm0065_p15.esp`.

## Printed in enough detail to reimplement
- **ESP class-definition syntax** (PDF p8). It has five parts: macro bank, nature (inheritance) definition, class slots and clauses, instance slots and clauses, and local clauses. The clauses of the component classes are **ORed in the order listed**. "*" marks the class's own position in the list (stated in TM-061 p4; in TM-065 it is only used). PDF p7–8.
- **Demons** (PDF p7–8). Before- and after-demons are ANDed with the inheritor's primary predicate. The inherited primary predicates are ORed.
- **Object representation** (Fig 2.1, PDF p6). An object is a KL0 heap vector. Element 0 holds the KL0 code executed on an operation call. The remaining elements are slots. The object pointer is the vector's location.
- **class file** (PDF p12–13). It has:
  - class slot pool_of_files;
  - class methods :create/1, :make/2 and :open/2, whose bodies are given;
  - instance slots and four instance-method signatures, whose bodies are elided ("...") in the original.
- **binary_file** (PDF p13–14). It has nature file, read/write signatures and the :tap body.
- **The window mixin example** (PDF p15–16). It covers bare_window, with_border, with_label and window_with_border_and_label, with bodies for refresh, initialize and the demons. The prose on PDF p16 gives the resulting refresh order: clear the area, then redraw the border and the label.

## Sketched only
- **Layering** (Fig 3.1, PDF p11). Programming system {Coordinator, Editor, Interpreter/Debugger, Library}. OS: I/O medium {Window, Network, File, Printer}; Supervisor {Process, Pool, Stream, World, Timer}; Kernel {Processor, Memory, Device}.
- **Elementary classes**: process, stream, pool and world. **Hardware classes**: processor and area. **Device classes**: disk and keyboard. All are named only (PDF p10).
- **The real class file inherits** as_permanent_object, as_resource and with_lock (PDF p13). These are named only.
- **History** (PDF p17). Design started in fall 1982. The class specification was completed at the end of FY1983. Cross-debugging ran on an ESP simulator, and PSI reached the software group in March 1984.

## Doubts
- with_border's first after-demon tests `border_flag == 0`, but the slot is initialised to `on`. TM-061 prints `== off`. Recorded as printed, in VARIANTS_tm0061_vs_tm0065.txt.
- The arities of the elided methods are taken from their printed heads.
