# TR-213 「PSIのガーベッジコレクタ」(西川 宏 他, Oct 1986). 9 PDF pages, Japanese; tesseract jpn triage (A/work/tr0213/ocr) + p4 read by eye at 300 dpi. TRANSLATION mine.

## Memory and GC (p4-5) -- the most concrete description of SIMPOS-level GC
- Each process owns areas: heap (H), global stack (G), local stack (L), control stack (C), trail stack (T) (Fig. 1 「プロセスとエリアの関係」, process i / process j each pointing to their areas). Heap area holds program object code and structure data (vectors etc.) (p5). Control-stack frames hold P-link (caller frame) and B-link (backtrack frame) (p5).
- Choice (p4): PSI has no secondary-storage paging, so grown areas must be compacted to free pages; hence a batch (stop-the-world) mark + sliding compaction GC. Each memory cell has 2 GC tag bits checked by hardware. A dedicated GC process allows fine-grained GC.
- GC process (3.3, p4): a software-level process started when a physical-page allocation request finds no free physical page. Two stages: (1) page-level GC: per process, reclaim pages of stack areas left unused after stacks shrank, returning physical pages to the real-page management stack; if enough pages are recovered, no cell GC; (2) cell-level GC: execute built-in predicate `collect-garbage(ProcessTable)` (printed with hyphen) which starts the microcoded GC routine: marks cells process by process for the processes named in ProcessTable, then compacts the marked areas. Going through software (not directly from the micro-interpreter) allows partial per-process GC by choice of ProcessTable, shortening pauses. REIMPLEMENTABLE at policy level (the SIMPOS side is: GC process + page reclamation + call of the built-in).
- Microcode size: marking ~1.0K steps, compaction ~0.5K steps (p4). Sections 4.1-4.2 (p5-8, OCR only): marking roots from local/global/trail/control stacks; compaction of stacks and of multiple areas (cites Morris's algorithm, because of inter-area pointers). Firmware-level detail, below SIMPOS; not transcribed.
- Cross-reference: TM-181/TM-229 system menu has a "garbage collection" media-system item; TM-143 p8: heap reclaimed only by GC, global stack only by backtracking.
