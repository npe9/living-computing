# TM-126 — 「マルチウィンドウシステムを通して見たインターフェースの考察」 (内田俊一, 辻 順一郎; June 1985, 8 PDF pp)

The report is printed Japanese in two columns. All 8 PDF pages were read by eye from 300 dpi renders. p1 is the cover and p2 is the introduction. Listings: `tm0126_p03.txt` (Fig 1), `tm0126_p05.txt` (Fig 2 and its table), `tm0126_p06.esp` (EXAMPLE class denwa), `tm0126_p06.txt` (Fig 3/4 screen text).

## Printed in enough detail to reimplement
- **Fig 2 redisplay bookkeeping** (PDF p5). The screen is cut into rectangles. For each rectangle, the system keeps the set of windows it contains (none / A / B / A and B). Each window's attributes are kept as an object, and its image is kept in memory at dot level. This is an algorithm outline with a worked example, not code.
- **Debugger parameter window** (Fig 4, PDF p6). Its exact items:
  - mode: trace / no trace / no debug;
  - print depth and length;
  - Trace/Leash port grid: CALL unify pick exit EXIT / FAIL next miss redo REDO, plus CALL EXIT REDO FAIL;
  - New / Method / Compiled / Builtin;
  - Spy Points.
- **Debugger Menu** items: Change State, Variable Window, Control Menu, From Last Input, From Whiteboard, To Whiteboard, Help.
- **file_manipulator menu**: abort, parent, refresh, make, undelete, expunge, purge, print, ^, v.

## Sketched only
- **PSI facts** (PDF p3). 30 KLIPS, comparable to DEC-10 Prolog on a DEC 2060. 80 MB main memory, as printed. More than 20 machines built, in use at ICOT and 8 makers. Design started mid-Showa 57 (1982).
- **Window manipulator** items MOVE, RESHAPE, SHOW and HIDE (PDF p5).
- **Parent/child windows** (PDF p5). There are parent- and child-window part classes (unnamed). The parent controls the layout and overlap of its children, and children can share the parent's keyboard entry.
- **Input routing** (PDF p7):
  - Each window has a fully-visible / not-fully-visible state. A fully visible window is the default selection.
  - The selected window's name shows on the bottom line, and its cursor blinks.
  - Mouse clicks go to the fully visible window under the cursor.
- **Session management** (PDF p7–8). Debugger command sequences are saved for replay.
- **Screens are dated** 23-May-85, "SIMPOS Version I.00", user tsuji.
