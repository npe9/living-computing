# TM-125 — "The Concepts and Facilities of SIMPOS Window System" (J. Tsuji, S. Uchida; July 1985, 25 PDF pp)

All 25 pages were read by eye. PDF page = printed "Page N" + 1. Listings: `tm0125_p04.txt` (Fig 1 and Fig 2), `tm0125_p05.txt` (Fig 3 hierarchy), `tm0125_p08.txt` (window manipulator items), `tm0125_p08_classes.txt` (ch.4 catalogue, 70 bullets / 69 names), `tm0125_p13.esp` (ch.5 method reference), `tm0125_p20.txt` (Tables 2/3), `tm0125_p23.esp` (Fig 6 EXAMPLE).

## Printed in enough detail to reimplement (interface level)
- **Chapter 5 method reference** (PDF p13–19). Signatures and one-line semantics:
  - creation: :create/1 and /2 with the Table 1 initiation options, plus the menu-item and choice-item vector formats;
  - attribute setters;
  - menu item add/delete;
  - border, label and margins;
  - activate, show, deactivate and hide;
  - text output: write, move_cursor, insert, delete, clear_line, scroll, open_rows, move_rows;
  - graphics: point, line, rectangle and string, with Line_width, Line_type and Alu variants;
  - markers;
  - :read and :read_sense, with input codes mouse$r, mouse$m, mouse$l, mouse$rr, scroll_request(Offset), abort and $$nil;
  - :kill.
  No bodies are given.
- **Concepts** (ch.2, PDF p4–8):
  - Output permission types: WAIT, NOTIFY, OUTPUT, SHOW.
  - Window statuses: exposed/deexposed and shown/unshown.
  - Input goes to the selected window.
  - Windows are registered to their creating process and killed with it.
  - The window tree is rooted at SCREEN.
  - There are temporary, menu and choice windows.
- **Window manipulator**: 12 items (PDF p8).
- **Measurement window nature list** (PDF p20). One concrete, ordered nature list: labeled_sash, as_scroll, as_output, as_graphics, as_markers, as_input, as_mouse_input, user_window.

## Sketched only
- **Chapter 4 class catalogue** (PDF p8–13). There are "about 120 classes", of which 69 are named with one-line roles. The groups are stand-alone, mixin (primitive / output / input / menu-choice) and internal. Internal classes include window_manager, display, screen, status_line, logical_mouse (a single_object), window_message, single_object and window_manipulator. No natures are given except two in prose: as_relation is inherited by as_superior, and logical_mouse inherits single_object.
- **Performance** (PDF p20–22). One-character output fell from 922 ms in the window manager to 15 ms with firmware support of method call and slot access. Input fell from 179 ms to 7 ms, about 4 ms of it in the keyboard handler. Font is 13×19 dots. The firmware group plans if_then_else.
- **Future plans** (PDF p24). Multi-font support. Standard I/O across the window, file and network media. Percentage-based automatic subwindow layout. About 30 PSIs are running SIMPOS 1.0.

## INFERENCE
Attaching the chapter-5 methods to class `window` in classes.tsv is my reading. The report documents them "for the window" without saying which class defines each one.
