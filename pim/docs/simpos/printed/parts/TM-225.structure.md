# TM-225 「AIワークステーションPSIのプログラミング環境」(Aug 1986). 16 PDF pages, Japanese. Read by eye: contact sheet of all pages, p5/p6/p14 at 300 dpi; OCR (simpos2/ocr/tm0225) poor. TRANSLATION mine.
- OS layers (p5): resource management (processor, memory, device management; IPL program), execution management (process, stream, pool, world, user, clock management), I/O media (window, file, network). Fig. 1 (p13) repeats this with PS = coordinator, editor, debugger/interpreter, library.
- Process management (p5) is "composed only of the class called process", which contains the management table and the operating program; outside the class only methods are visible. Usage (p6): `:create(#process,P)`, `:activate(P,Program)`, `:terminate(P)`. General system-service pattern: create an object from a class, call its methods, call its termination method.
- Window system (p14, Fig. 2): user processes talk to the window manager; window manager uses window objects/window classes and drives bitmap, keyboard and mouse handlers. Fig. 3 window hierarchy under the screen. Fig. 5 (p15): overlapping is handled by copying obscured contents between frame memory and per-window save areas (INFERENCE from box labels: each window has a save area used when stacking order changes). Text (p9-10, not eyed in full) describes output to covered windows.
- Size (p11, from contact sheet + OCR): source ~230,000 lines, ~1,400 classes, ~18,000 methods(?) (same numbers as TR-285).
