# TM-785 「PSI図形ツールのインストール方法」(東 吉郎, Aug 1989). 40 PDF pages; an application (PSI graphics tool) manual. Read: p3, p40 by eye; others by OCR triage.
- Librarian install from floppy (p3, listings/TM-785_p03.txt): create a librarian, insert floppy in unit 0, choose "Execute", type `Command>fdd("drawing.com")`, answer "FDD mount ok? Input unit No. (0):0". If the package exists: "Error occurred in librarian_59( process 59 ) / Package drawing already exists / Cannot load package_template_file" with an error-handling menu (Erase existing package and continue / Inspect the information of this event / Return to librarian top level). Shows: librarian is a process named librarian_<n>; packages have a "package template file"; librarian command files (.com) are run from the floppy; the error menu is the situation/event mechanism's recovery menu (INFERENCE linking to TM-181 p5).
- File identifiers "draw" and "image" for saved files (p22-24); fonts addressed by pathname, e.g. ">sys>font>kanji_16.font" (p40).
- pp29-40: generated ESP class graph_drawing (application, EXAMPLE); p40 data table gives the window drawing method names and argument tuples (line style solid/dotted, fill patterns mesh/left_hatch/small_mesh, op set or colour numbers). Not transcribed: pp29-39 (≈11 pages of application ESP).
