# TM-229 「SIMPOS（逐次型推論マシンPSIのOS）―ユーザ・インタフェースとその特徴―」(佐藤裕幸 他, 1986-09-29). 9 PDF pages, Japanese; read by eye pp2-5 (100/400/600 dpi); listings/TM-229_p03-05.txt. TRANSLATION mine.

- English abstract (p2): SIMPOS project started May 1983; source program "more than two hundred thousand lines".
- Layering (p3-4) -- the 1986 version of the TM-143 list, with changes: kernel = processor, memory (allocation and address-space management **incl. GC**), device, **kana-kanji conversion built into the keyboard handler** (so kanji can be input anywhere), IPL (loads and initialises SIMPOS). Supervisor = process, pool, stream (communication and synchronisation), **wildcard**, **directory**, **user management** (logged-in users). I/O media = window, **font** (font management), **symbolizer** (string <-> structure), file (disk), **magnetic tape**, **printer**, network (other PSIs and mainframes). PS = tools plus manipulators.
- Fig. 2-1 (p3) adds: situation (exception handling) in the supervisor ring; text buffer, library in the I/O ring; call counter, font editor, inspector/debugger, system debug tool, window manipulator, editor (PMACS/EDIPS), coordinator/shell, librarian, file manipulator, spooler manipulator, magnetic-tape manipulator, file transfer?, talk, mail? in the outer ring; KL0 vs KL0/ESP boundary.
- Comparing TM-143 (1985) and TM-229 (1986): kanji moved into kernel; clock, remote object, system tracer no longer listed in the supervisor; library moved to I/O ring in the figure (INFERENCE from label placement, low-res figure).
- p5: system menu (EXPERTS multi-instance; MEDIA SYSTEMS single-instance; users can add/remove EXPERTS entries); items include demo programs Escher, Oekaki, Queens, Squares, Bounce; login sets directory logical names and runs an initialisation program.
