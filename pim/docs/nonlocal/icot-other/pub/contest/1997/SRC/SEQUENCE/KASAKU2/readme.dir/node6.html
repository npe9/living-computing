ストレート検索

ストレートフラッシュの余りカードから、フラッシュとストレートを作るの が目的である。各Kindについて余りカードから (余りカード数) mod 5 枚を 使ってストレートを作る。一度に解くのは難しそうなので、いくつかの段階 に分割した。

  1. Kind自体は考慮せずに、各Rankのカード数のリストから、可能なスト レートの組のRankを決定し、出力する。複数の組が出力される。
  2. ストレートのRankの組から、各ランクのカードの必要数を算出する。
  3. (2)の必要数と、各Kindの使用可能カード数制限を満たすカードの組 合せを片っ端から探す。
  4. 条件を満たす組みが一つでもあれば、探索を終了して、使用カードの リストからストレートを再構成する。
