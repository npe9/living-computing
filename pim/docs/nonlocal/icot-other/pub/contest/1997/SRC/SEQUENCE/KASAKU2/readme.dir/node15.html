疲れた。

わりと自由にKLICでプログラムが書けるようになったと思う。 ただ、文法などを全く知らないところからスタートしたこともあり、 今から見ると随所に効率の悪い書き方をしているところがある。 得点計算部以外でもベクタ等を使うべき所があるし、 マージャも組み込みのものを使ったほうがよい。 とはいえ、自分としては予定どうりの、わりと満足のいくプログラムである。 高速性に関して言えば(少なくとも開発に使った環境では)予想以上であった。

KLICのプログラミ ングではデータのフローや流すデータの形式を考えるのが重要であると思うが、 同時にこのことが比較的大規模なプログラムを書く際でも問題の難しさの(幾何 級数的な)増大を防いでいるように思われた。問題の分割の重要性を改めて思 い知った次第である。
