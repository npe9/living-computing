B.6 utils モジュール

 

opponent +Symbol, -OppSymbol
記号 Symbol の相手の記号を OppSymbol に同一化する。 Symbol が数値化されている場合は、 OppSymbol も数値となる。
out_brd +Board
局面 Board を出力する。
print +X
io:outstream/1 を用いて X を出力する。
printn +X
io:outstream/1 を用いて X を改行付きで出力する。
