Table search

The primitive commands of table manipulations explained below are restricted to those used in a personel management system irpr.

search_index(TableName,SearchIndexCondition,^Set, ^Status)
searches using indexes and returns a set of result.
search_data(TableName,SearchDataCondition,^Set, ^Status)
searches without using indexes, i.e. searches by reading each record directly and returns a set of result.
search_data(TableName,{Set,^NewSet},SearchDataCondition, ^OutSet,^Status)
searches in a given set "Set" and returns a set of result in "Outset".
