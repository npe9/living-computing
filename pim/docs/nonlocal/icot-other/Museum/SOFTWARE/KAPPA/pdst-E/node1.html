Preface

This guide is to help beginners who want to write application programs of Kappa DBMS developped in ICOT. This is partly based on beginners' manual on applications of Kappa ESP version.

Firstly, we describe the data model of Kappa. Then, the primary commands of Kappa are explained. Because of the characteristics of this guide, they are restricted to those used in a personal management system irpr which is an application of Kappa. Therefore, please see Kappa user's manual for the explanation of other commands or the details of vocabulary.

In the end, we introduce the personel management system irpr as a programing example. Irpr is a socket client type program explained in Kappa install manual. Programs of this type are recognized as more generic than KLIC client type programs.
