Programing interface

The programing interface of Kappa system is given by the primitive commands. They are primitive operations on nested relations and are based on pointer manipulations by record identifiers.

Following are the primitive commands.

Job and transaction control
open,close,begin_transaction,end_transaction,roll_back
Search
search_index,search_data,...
Read
read_record,...
Update
add_record,replace_record,delete_record,...
Set operation
set_operation,...
Other
get_table_info,get_attribute_info,...
