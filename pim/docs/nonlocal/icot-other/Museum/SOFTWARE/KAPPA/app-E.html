Kappa programing

Kappa does not have its own GUI but has primitive commands as a KL1 programing interface. Therefore, you have to write application programs of Kappa to operate databases. This job might be difficult because experience of client server programing in KL1 and consideration of enormous amount of data are ncessary. Thus we wrote Kappa Programing Guide using a personel management system irpr as an application example. In order to use the personel management system, see A Personel Management System irpr User's Manual.

Though irpr has an emacs interface, corresponding parts are not included in the programing guide and other software including documents released in IFS Kappa.
