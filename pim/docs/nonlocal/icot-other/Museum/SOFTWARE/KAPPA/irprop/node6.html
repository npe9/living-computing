名簿管理のディレクトリ作成

名簿管理DB及びシステムファイルなどは、例えば、次のようなディレクト リを作成して配置する。

~/irpr
database.init, startup.kappa, AddInput.docファ イルを置く。
kappaコマンドは、このディレクトリで呼ぶ。
database.init
データベース初期化ファイルである。内容例を次に 示す。 
     page_size(4096).
     ldbms("LDBMS000"):-
         control(500),index(3500),record(3500),overflow(100),log([{1000,3}]).
startup.kappa
kappa構成ファイルである。内容例は次の通り。 
     [
      {"LDBMS000",
        {{150,500,10,2},{{{200,100},{200,100},{2,1}},20},{"system",'CLM_Table',10,10}},
        ["CA000","IA000","RA000","OA000"],"LG000", 0, nil}
     ].
AddInput.doc
レコード追加ユーティリティで使用するファイルであ る。テーブル定義に関する情報を、次のように記述する。 
      [meibo_history([1]),meibo([1]),meibo_id([1])].
すなわち、meibo_history,meibo,meibo_idという３つのテーブルが、水平分割 なしで定義された。

~/irpr/bin
kappa実行ファイル、irpr_client実行ファイルを置く。 これらのプログラムの実行のために、パスを切っておく。
