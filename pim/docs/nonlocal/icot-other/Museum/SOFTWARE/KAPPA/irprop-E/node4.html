Setting hash keys

The hash keys are defined in get_hash_key/2 of /Kappa/src/add_utl/kp_schema.kl1 as follows. 

get_hash_key(meibo,Key) :- Key = id.
get_hash_key(meibo_history,Key) :- Key = id.
get_hash_key(meibo_id,Key) :- Key = id.
