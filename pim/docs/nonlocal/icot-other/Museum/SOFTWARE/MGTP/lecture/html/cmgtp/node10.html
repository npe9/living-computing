QG5.5に対するCMGTPのルール

図にQG5のオーダ5に対するCMGTPの入力節を示す。 (CM1)から(CM5)はオリジナルのMGTPでのルールと同じである。 (CM6)-(CM9)も同様に準群の定義と同型排除の ヒューリスティックスを表しているが、 条件にあわない候補をあらかじめ否定モデルとして生成するルールに 置き換えられていることに注意されたい。

そして、(CM10)-(CM18)はQG5での制約条件を表現したものとなっているが、 これは、図で示した制約伝搬ルールそのものになっている。 すなわち、図に示されるような制約伝搬ルールは CMGTPの入力節としてダイレクトに記述することが可能であり、 この意味で、CMGTPは制約伝搬を記述するメタ言語と考えられる。
