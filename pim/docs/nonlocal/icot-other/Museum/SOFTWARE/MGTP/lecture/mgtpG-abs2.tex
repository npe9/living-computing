\section{例題}

また、8 クイーン問題を MGTP で記述した例を
図\ref{queen}に示す。
述語 p(M,N) は M行N列に
クイーンが置かれることを表している。
はじめに正節として、各行における値の候補が選言の形式で記述されている。
ここの例では、\verb+{{ }}+で囲まれたプログラム呼び出しが用いられており、
これにより、同じ行や同じ列、あるいは対角線上にクイーンが置かれた
ことを判定し、モデル候補を棄却するようになっている。
