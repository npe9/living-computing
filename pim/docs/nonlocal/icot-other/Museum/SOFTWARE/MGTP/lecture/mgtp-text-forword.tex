
\chapter*{はじめに}
本編は KLIC/MGTP講習会のために作成した
モデル生成型定理証明システムMGTPに関する入門テキストである。

MGTPを使って自動定理証明が簡単にできるよう
極力やさしく解説するよう努めたが、
一階述語論理についての基礎知識がいくらか必要かもしれない。
また、KL1言語については講習を一通り修了していることを前提とする。
不明な点が生じた場合には、「KLIC講習会テキスト---KL1言語編」と
「同---KLICシステム編」を本編と合わせてご利用願いたい。

本編では例示用の問題以外にもいくつか
演習問題を付け加えるので、
実際に自分でMGTPを使って解いてみることをお奨めする。

なお一部の内容は、新世代コンピュータ技術開発機構による
IFS (ICOT Free Software) に収録されている
MGTPシステムのマニュアルより引用した。
