\begin{ohp}
\ottl{値域限定条件}

MG節：
\[
   前件\longrightarrow 後件
\]
において、
後件に現れる変数は、すべて前件に現れていること。

\end{ohp}

%-----------------------------------------------------------------------------

\begin{ohp}

MG節：
\[
   true\longrightarrow p(X).
\]
において、後件に現れる変数Xが前件に現れていない。

このとき、
\[
   dom(a)\longrightarrow p(X).
\]
のように、前件に$dom(変数)$を補う。

\end{ohp}

%-----------------------------------------------------------------------------

\begin{ohp}

さらに、

そのMG節集合に現れるすべての定数について、
\[
   true\longrightarrow dom(定数).
\]

そのMG節集合に現れるすべての関数\hfil\break
($f_1(・),f_2(・,・),\ldots$)について、
\[
\begin{array}{rcl}
          dom(X)&\longrightarrow& f_1(X).\\
   dom(X),dom(Y)&\longrightarrow& f_2(X,Y).\\
&\cdots&
\end{array}
\]
を補う。

\end{ohp}
