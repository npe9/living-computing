準群問題における制約伝搬

準群問題において必要とされるべき制約伝搬についてまとめよう。

図は、 QG5において必要とされる制約伝搬ルールを前向き推論形式で記述したものである。 ルール(a)は、任意の x, y, a, b に対して、 yx=a, ay=b が成り立つならば、by は x でなければならないことを 表しており、(b)(c)はルール(a)の対偶をとることによって得られる。 これらのルールは負の情報からの制約伝搬を行なう際に必要とされるが、 その意味するところは直観的に明らかであろう。 また、ルール(d)(g)は、準群の定義によりルール(a)より導かれるものである。 ルール(e)(f)はルール(d)の、またルール(h)(i)はルール(g)の対偶 としてそれぞれ導かれるものである。
