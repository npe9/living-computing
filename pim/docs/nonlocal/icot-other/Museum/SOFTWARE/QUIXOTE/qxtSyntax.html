Quixote のプログラムと質問の構文を説明しましょう。

プログラム

Quixote のプログラムは、次のような &program;; と &end. に囲まれたものです。 

						&program;;
						   …
						   …
						&end.

そして、 &program;; と &end. の間 （上記の … の部分）には、次のものを書くことができます。

  • 環境定義
    プログラムの作者名などが書けます。
  • 基礎オブジェクト項間関係定義
    ここに書かれた関係を元に、 属性継承 と 制約解消 が行なわれます。
  • モジュール間関係定義
    ここに書かれた関係を元に、 ルール継承 が起きます。
  • ルール定義
    ここにルールを書きます。

ここで、 Quixote プログラムとして、 サイダー を紹介しましょう。

質問

Quixote の質問は、次のように「質問モード」というものを 付加することができます。
  • ?- ボディ ;; 質問モード指定 .

サイダー を用いて、 質問の例 も ここで少し紹介します。
