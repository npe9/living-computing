入門

Quixote を分かり易く解説しましょう。

まず「キホーテ」と聞いて、スペインの作家セルバンテスの 小説「ドン・キホーテ」を思い出された方も多いと思います。 それで、「なぜ、 Quixote と命名されたのか？」という謎が 最初に浮かんだと思います。

それをまず解明なさりたい方は、こちらを御覧下さい。 「命名の謎！！」
「解明したいけど、ヒントもちょっと欲しいなっ！ (^^)」と思われる方は、
＜こちら＞をどうぞ。

さて、次に「 Quixote とは実際何なの？」と思われる方へ。
「 Quixote とは」 が、 その特徴を踏まえながら簡単に Quixote を説明しています。

ここで、 「命名の謎！！」 と 「 Quixote とは」 を 書くにあたって参考にしたものを紹介しましょう。 「おかしい！」、あるいは、「もっと知りたい！」などと 思われたら、 参考文献を 御覧下さい。

上記の 「 Quixote とは」を 読まれて、「何だかあっさりし過ぎだなぁ〜、もっと詳しいことが 知りたいなぁ〜」と思われた方へ。
只今、「 Quixote 入門こってり味版」を作成中です。乞う御期待！！ (^^)
