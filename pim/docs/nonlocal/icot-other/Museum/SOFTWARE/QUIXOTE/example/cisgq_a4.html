「ウィーン売買条約第ＩＩ部」の問合せと答えの例４

「２番目の申込は効力があるか？」の問いは、

	?- effect_def:申込[順番=2].
と記述されます。

次に答を示します。

Quixote からは例えば以下のような答が返されます。 
	IF fact:回答[順番=2].行為==配達[場所=個人]
	THEN YES
	IF fact:回答[順番=2].行為==配達[場所=営業所]
	THEN YES
	IF fact:回答[順番=2].行為==配達[場所=郵便送付先]
	THEN YES
です。最初の答えは 
	もし、２番目の回答が相手方に個人的に伝えられたなら、
	YES です。
を表しています。他も同様です。
