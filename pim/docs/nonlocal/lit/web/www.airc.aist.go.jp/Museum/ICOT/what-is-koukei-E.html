Research Results of Follow-on Project

Research Areas in the Follow-on Project:

  1. KLIC system: a KL1 programming environment for sequential and parallel Unix-based machines
  2. Evaluation of PIM's and KL1 language processor
  3. Parallel Nested Relational DBMS, Kappa-P
  4. Parallel theorem prover, MGTP
  5. Knowledge representation languages;
    • Deductive and object-oriented language, Quixote
    • Parallel constraint logic programming language, GDCC
    • Heterogeneous distributed problem solving system
  6. Genetic information processing systems
    • DNA and protein sequence analysis systems
    • Biological DBMS and KBMS
  7. Legal reasoning system, HELIC-II
Please refer to the Proceedings for Internation Symposium on Fifth Generation Computer Systems 1994.
