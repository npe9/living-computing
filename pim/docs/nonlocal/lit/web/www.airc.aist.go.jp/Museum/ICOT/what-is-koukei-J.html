FGCS後継プロジェクトの研究成果

FGCS後継プロジェクトにおける研究分野:

  1. KLICシステム: Unixベースの逐次マシン、および 並列マシン上のKL1言語処理系 (プログラミング環境)
  2. 並列推論マシン (PIM)、および PIM上のKL1処理系の評価研究
  3. 並列非正規関係データベース管理システム Kappa-P
  4. 並列定理証明システムMGTP
  5. 知識表現言語と知識べース管理システム
    • 演繹オブジェクト指向に基づく知識表現言語 Quixote
    • 並列制約論理プログラミング言語 GDCC
    • 異種協調分散問題解決システム Helios
  6. 遺伝子情報処理システム
    • DNA および タンパク質の配列解析システム
    • 分子生物学データベース、 および 知識ベースシステム
  7. 法的推論システム、新HELIC-IIシステム
後継プロジェクトの最後に、同プロジェクトの成果を発表した、「第五世代シンポジウ ム１９９４」の予稿集もあわせてご覧下さい。
