Overview

A visualization system which visualizes and manipulates protein molecules using the 3D- Talk and Protein-Talk description languages.

Features

  • A three-dimensional graphical visualization system which interprets an original description language.
  • An object-oriented language, 3D-Talk, with syntax similar to English, for describing graphical objects.
  • A protein structure manipulation language, Protein-Talk, which visualizes and animates three-dimensional protein stuctures.

Function

This system is built up of two parts, a three-dimensional visualization tool, 3D-View, and a protein structure visualization tool, Protein-View. Protein-View generates statements in 3D-Talk, and 3D-View interprets these statements and displays the protein structures.

3D-View is designed to provide users with an easy visualization environment. 3D-Talk is a graphical object description language that can describe almost any kind of three-dimensional object. The syntax of this language is similar to that of English. This feature is quite useful for those inexperienced in computer languages. The visualized objects can be manipulated by mouse operation. Users can rotate, move, and magnify the objects. The control panel provides another way to manipulate the objects and to change the configuration and environment. Also, these operations can be done by using statements in 3D-Talk.

Protein-View reads the data in PDB(Protein Data Bank) and visualizes the protein structure. This tool provides a function to show the topology of protein structure using ribbons, eand provides a function to change the dihedral angle of chemical bonds for animating molecular dynamics.

This system can be applied to protein structure design or to simulation of molecular dynamics and other fields of visualization, such as robot design.
