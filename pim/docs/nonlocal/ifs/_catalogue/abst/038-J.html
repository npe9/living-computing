概要

自然言語処理において、文法開発のための支援環境を提供するツールである。

構成

　　　　　　　┌────────────────────────┐
　┌────┐│　　　　　　　┌─────────┐　　　　　　│
　│文法規則├┼──────＞│Ｇｅｎｅｒａｔｏｒ├──────┼─＞　パーザ
　└────┘│　　　┌──＞│　　　　　　　　　├─┐　　　　│
　　　　　　　│　　　│　　　└─────────┘　│　　　　│
　　　　　　　│　　　│　　　　　ＬＩＮＧＵＩＳＴ　　│　　　　│
　　　　　　　│　　　│　　　　　　　　　　　　　　　Ｖ　　　　│
　　　　　　　│┌──┴─────┐　　┌────────┐　　│┌─────┐
　　　　　　　││Ｄｅｂｕｇｇｅｒ│＜─┤Ａｃｃｅｓｓｏｒ│＜─┼┤評価用例文│
　　　　　　　│└────────┘　　└────────┘　　│└─────┘
　　　　　　　└────────────────────────┘

　　Generator:　ＤＣＧ記述の文法からパーザを生成する
　　Accessor :　パーザを起動し、文の解釈を行う
　　Debugger :　文解析過程をトレースし、文法を修正する

機能

実用的な規模の自然言語処理を行うためには大規模な文法が必要である。 LINGUISTは、修正→実行→評価→修正という、文法開発の基本サイクルを効率 よく進めることで文法開発者を支援する。文法規則の規模が大きくなっても、 その修正、改良において、全体の整合性を取ることができる。

本プログラムは、CESP で記述されており、UNNIX マシン上で動作する。文法 の開発、修正等の作業が無駄なく行われるよう対話型の利用者インタフェース を持つ。加えて視覚化デバッグ環境、文法規則のソースレベルでのトレース機 能を提供している。

尚、LINGUIST には、日本語解析のための文法規則と辞書が予め言語知識ベー スとして付随している。この文法規則は、日本語の基本的な言語現象をカバー している。さらに規則の機能に関する詳細な説明書が提供されているので、利 用者は文法開発環境と言語データベースの双方を使って効果的に文法開発を行 うことができる。
