Overview

A tool for deviding a long sentence at a conjunctive particle.

Function

A long sentence has many ambiguities. This tool can resolve ambiguity of a long complicated Japanese sentence by dividing it at a conjunctive particle into some simple sentences.

  • This tool can divide a sentence at 13 conjunctive particles.
  • When the sentence has some conjunctive particles, preference rule decides at which conjunctive particle it should be diveded.
  • Tense rule decides tenses of the devided sentences.
  • This tool can devide surface sentence by using LAX for morphological analysis.

Example

Input
Kare wa ongaku kai he iku kawarini record wo katta.

(Instead of going to the concert, he bought a record.)

Output
Kare wa ongaku kai he ika nakatta. Sonokawari record wo katta.
(He didn't go to the concert. Instead, he bought a record.)
