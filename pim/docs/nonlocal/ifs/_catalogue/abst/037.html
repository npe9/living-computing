Overview

A total supporting tool for the development of morphological analyzer and its dictionary.

Features

  • Morphological analyzing program:
    - Outputs all interpretation at one time as a graph stack structure
    - Recognizes unknown words and location of failure point in analysis easily
    - Can be used as a server program on UNIX system
  • Dictionary developing environment:
    - Results of the analysis including ambiguity and occurrence of unknown words are displayed effectively
    - Registration and deletion of entries, and revision of definition for categories can be executed instantly for the intermediate dictionary

Function

This system provides a common development environment of morphological analyzer and its dictionary for NLP system developer and enables them to get morphological analyzer they need easily.

In this system, user describe a morphological dictionary first, in which morphological categories with their connection information and morphemes of each category should be defined. Next, the user translate this dectionary into an intermediate dictionary, with which one can perform analyzing test, modify the attributes of categories and add new entries instantly. This analyzer can be combined with other applications on CESP.

Moreover, this system can transform the analyzer into a server program on UNIX system. Using the server combined with various applications developed on UNIX system, one can make a NLP system efficiently, which would be very practical because a server program can be accessed by many people simultaneously. This server program performs not only morphological analysis but also revision of intermediate dictionary such as addition of entries. Then, one can take advantage of this function to build a flexible application.
