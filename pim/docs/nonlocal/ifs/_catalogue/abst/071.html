(71) A Diagnostic and Control Expert System based on a Plant Model

	Machine:     Multi-PSI
	Environment: PIMOS 3.01
	Language:    KL1
	Source Code: 3.1 MB
	Documents:   None

Overview

This system can generate IF-THEN type knowledge to control a plant using the models of the plant.

Purpose

This system is developed to demonstrate the applicability of MBR and logic programming to a thermal power plant control.

Configuration

Function

Diagnosis by the Qualitative Causal Model and the symptoms clustering technique. (Diagnosor)
Compilation of plant control rules by the Device Model and the Operation Principle Model.
- Generation of operations (Operation Generator)
- Generation of preconditions to the operations (Precondition Generator)
Verification of compiled rules by the Dynamics Model (Simulation-Verifier)
