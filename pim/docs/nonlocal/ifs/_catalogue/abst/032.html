Overview

Structure-Mapping Engine is a program which extracts correspondances and their similarity between two systems described in the tree form based on structure-mapping theory.

Configuration

Structure-Mapping Engine consists of pair set creation module, pair set connection(correspondence creation) module, correspondence similarity evaluation module, and inference candidate creation module.

And as interface modules, tree editor and correspondence browser are available.

Function

  • Extraction of given base structures similar to given target structures from memory.
  • Creation of the correspondences between base and target.
  • Inference of the lacking relations in target which exist in base.
  • Evaluation of similarity of the correspondences.
  • Support of graphical input of base data and target data.
  • Browsing the extracted correspondences graphically.
