Overview

This system is to cooperate morphological analysys, syntactic analysis and semantic analysis of natural language processing.

This program realize the parallel cooperation with This system have been confirmed a speed-up of a factor 13 when utilizing 32 processor elements of Multi-PSI.

Function

The Function of this program is to cooperate morphological analysis, syntactic analysis and semantic analysis of natural language processing. We provided a interface to exclude the cooperation with semantic analysis. This interface is useful to examine the effect of the cooperation with semantic analysis. We used the syntactic grammar which were developed by Sano of ICOT.
