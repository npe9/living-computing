Overview

This system realizes a protein motif knowledge-base and its retriever using deductive object-oriented database language QUIXOTE.

Features

  • An application system of deductive object-oriented database language QUIXOTE.
  • The system deals with motif data contained by Prosite.
  • Motif relations are properly managed by module structure and attribute inheritance mechanism.

Function

Primary structure of protein is a sequence of amino acids, in which we can find some feature patterns called motifs. A motif is a meaningful unit which characterizes a protein in terms of its function. In this system, motif data obtained from world-wide database Prosite(Rel.9.0) are classified and organized in the framework of QUIXOTE. Each motif is represented as an object and a bunch of objects are managed as a module. Because relations among modules are explicitly described in QUIXOTE, we can efficiently retrieve some related motifs from a biological point of view.
