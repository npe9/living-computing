Overview

KL1 is a concurrent logic programming language. This system is for trying out a portable implementation scheme of KL1.

Features

  • Full portability and reasonable efficiency by compiling KL1 programs into C programs.
  • Only those KL1 functions which are frequently used and have a significant impact on efficiency are implemented.

Function

KLIC is an implementation of a concurrent logic programming language, KL1. KL1 is based on a flat version of the Guarded Horn Clauses(GHC) language. GHC is a member of the committed-choice logic programming language family and has siblings such as Concurrent Prolog, Parlog, Janus, and Fleng.

In the KLIC implementation, KL1 programs are compiled into C programs and then compiled and linked with runtime libraries by C compilers.

The current system is a sequential implementation.
