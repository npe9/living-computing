Overview

A Support System for Generating Controled Japanese Text and Semantic Structures

Configuration

ICOTEXT is an integrated natural language processing system including morphological analysis, syntax analysis, semantic analysis, and sentence genaration. ICOTEXT analyzes input Japanese sentences, generating two kinds of outputs:

  1. clearer surface sentences with less ambiguities
  2. semantic structures of input sentences

Function

  • morphological analysis by LAX
  • syntax analysis by SAX based on dependency grammar
  • semantic analysis based on case frame
  • based on "Controled Japanese" grammars proposed by Prof. Yoshida
  • ambiguity resolution by morphological replacement and sentence division
  • semantic representations within Shared Directed Graphs(SDG for short)

Reference
