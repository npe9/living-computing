Overview

Language system providing fundamental facilities for knowledge information processing, such as knowledge representation and inference.

Features

Equipped with many functions,QUIXOTE becomes too large system to run easily. u-QUIXOTE, on the other hand,aims to implement core features of QUIXOTE as small and light as possible. It has also good portability and you need only C compiler to install u-QUIXOTE.

Functions

u-QUIXOTE provides several facilities for developing experimental systems for knowledge information processing,such as natural language processing,legal reasoning,and so on.

u-QUIXOTE is a language for deductive object-oriented databases,and can be seen as an extended CLP language in terms of subsumption constraints having object-orientation features.

  • Object identity defined over extended terms(object terms),
  • Constraints over subsumption relation among object terms,
  • Property inheritance defined in terms of subsumption constraints,and
  • Answers with assumed constraints.
