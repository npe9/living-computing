(69) Case-Based Circuit Design Support System

	Machine:     PIM/m, Multi-PSI
	Environment: PIMOS 3.4
	Language:    KL1
	Source Code: 6 MB
	Documents:   None

Overview

System supports a user in designing a new circuits using similar precedential circuits.

Configuration

  • Function Analysis Module for Design Specifications
  • Case Retrieval Module
  • Case Modification Module
  • Circuit Block Diagram Output Module

Function

  • Functional hierarchy trees, that represents functional structures of design objects, are created interactively and used as indices for case retrieval.
  • Structure Mapping Engine (SME) retrieves the cases whose functional structures are similar to the design object's.
  • To shorten run-time, cases are retrieved parallel. The structures of the design object and cases are mapped into each processor in good balance.
  • System verifies detail specs of retrieved cases, modifies them, recovers design failures with SME, and dembines circuit blocks.

Reference

  • Morishita, T., et al. : A Case-Based Reasoning System using Structure Mapping, Proc. of the 17th JSAI KBS, 1991(in Japanese)
