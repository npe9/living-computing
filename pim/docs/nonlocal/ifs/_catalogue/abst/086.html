Overview

Distributed pool provides basic in-memory database features where data are distributed to many processing nodes.

Features

  • The contents of a pool are cached on each node to reduce the cost of access on each node.
  • The distributed pool distributes memory cunsumption to many processing nodes, making the maximum capacity of the pool much larger.
  • Application programers can distribute the computing load flexibly without worrying about data consistency.

Function

The distributed pool stores data with a search key and enables its extraction and reference according to its key. It provides the following functions:

  • Referring data.
  • Adding data.
  • Extracting data, if any, and then storing new data with the same key.
  • Extracting data, if any, and then storing new data with the same key. If there is no corresponding data, the new data is not stored in the pool either.
  • Extracting data if any with the given key exist.
  • Deleting data.
