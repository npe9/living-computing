\section{概要}

このマニュアルは、new-HELIC-IIのGUI (Graphical User Interface)を使って
論争をいかに行なうかについて説明する。
論争機能についての概念的な説明は\ref{ronsou}に詳しく書かれている。
実際に使ってみる前にこの章に目を通しておくことを推奨する。
またマニュアルの中で使われている用語は、その場で簡単な説明を加えているが、
系統立てて理解するために、言語マニュアルの通読を推奨する。

\section{基本知識}

\subsection{論争モデル}\label{ronsou}

HELIC-IIの論争機能は、検察側と被告側という２つのエージェントの
間の論争モデルを実現したものである。

論争における検察エージェントの目標は、自身のゴールを正当化する論証を
生成することであり、
被告エージェントの目標は、その論証に対する有効な反論を生成することである。

この論争モデルの前提は以下の通りである。

\begin{itemize}

\item 双方のエージェントは、それぞれ異なる知識(価値観,ルール集合)を持つ。
\item 検察エージェントのみが論争の中で達成すべきゴールを持つ。
そのゴールはH項\footnote{H項については言語マニュアルを参照}として表現され内部に変数を含んでいても良い。
被告は検察の出した論証に対して受動的に反駁を行なう。
\item 双方の主張は、事実に基底する推論木の形をした論証を用いて
行なわなければならない
\item 論証間の比較は、論証のtop-ruleの間の優先関係によって決定される
\footnote{Sub-Argumentの評価をしないでTop-Ruleのみで優先関係を決めている
ことが、Defeasible Reasoningでの論証の比較とは異なる}。

\end{itemize}

論争の過程において、双方が、自分の価値観の基で優位になる論証を
相手に主張(pose)したり、 自分の論証の方が相手の論証より優位であることを
通知(notice)することにより、論争を進めていく。

% +----+  	---->  		+----+
% |検察|     論争プロトコル 	|被告|
% +----+  	<----  		+----+
%   |		  	  	  |
%   V		  	  	  V
% +===========+	       		+===========+
% |価値観1    |	       		|価値観2    |
% |ルール集合1|	       		|ルール集合2|
% +===========+	       		+===========+
% 
% 		[ 論争モデル ]

各エージェントは論争プロトコルと呼ばれるメッセージを相手に通知することにより、
自分の考えを相手に通知する。以下にその種類を示す。

\begin{enumerate}

\item 論証主張(pose)\\
	自分の論証を相手に主張する。相手に主張や反論をしたい時に使う。
\item 優先通知(notice)\\
	自分の論証の方が優位であること通知する。
\item 論証棄却(cancel)\\
	自分が以前通知した論証を棄却する。
\item 論争終了(finish)\\
	相手論証について論争が終了したことを通知する。

\end{enumerate}


\section{HELIC-II GUIの仕組み}

\subsection{構成}

HELIC-II GUIは二つのUnix Processから構成される。
一つは、KL1によって書かれた推論エンジン部で、もう一つはCで書かれたGUI部である。
これら二つのUnix Processはソケット通信によって結ばれている。
HELIC-IIを立ち上げるには、これら二つを推論エンジン、GUIの順で立ち上げ
なければならない。起動方法については \ref{KH} を参考。

\subsection{GUI実行時の状態遷移}

論争機能を実行するGUIには以下の３つの状態があり、 状態に応じて使えるコマンドが
制限される。起動時は初期状態である。

%	   	  debate,rbr		      start
%+--------+  	--------> 	+--------+  --------> 	+--------+
%|初期状態|		  	|設定状態|              |論争状態|
%+--------+	<-------- 	+--------+  <-------- 	+--------+
%		  quit			      end

\begin{enumerate}
\item 初期状態:

\begin{enumerate}
\item 使用可能コマンド
\begin{itemize}
\item 知識ベースロード関連
\item 論争エージェント役割設定
\end{itemize}
\item 状態遷移コマンド\\
DebateもしくはRBRで設定状態に移る。
\end{enumerate}

\item 設定状態: 

\begin{enumerate}
\item 使用可能コマンド
\begin{itemize}
\item 価値観設定
\item ゴール設定
\item 使用ユニット設定
\item 論証ブラウザ関連コマンド\footnote{論争が既に一度終って論証が
表示されている場合のみ}
\end{itemize}
\item 状態遷移コマンド\\
Quitで初期状態に戻り、Startで論争状態に移る。
\end{enumerate}

\item 論争状態:

\begin{enumerate}
\item 使用可能コマンド
\begin{itemize}
\item 論争関連コマンド
\item 論証ブラウザ関連コマンド
\end{itemize}
\item 状態遷移コマンド\\
Endで設定状態に戻る。
\end{enumerate}

\end{enumerate}

なお、初期状態から設定状態へ行くためには以下の処理を必ず行なわなけ
ればいけない。

\begin{itemize}
\item 知識ファイルの読み込み。詳しくは\ref{FLW}を参照のこと。
\item 論争当事者の設定。詳しくは\ref{YSW}を参照のこと。
\end{itemize}

また、設定状態から論争状態へ行くためには以下の処理を必ず行なわなけ
ればいけない。

\begin{itemize}
\item 使用知識の設定。詳しくは\ref{CSW}を参照のこと。
\item 価値観の設定。詳しくは\ref{KSW}を参照のこと。
\end{itemize}

\section{起動方法}\label{KH}

HELIC-II GUIを起動するには、Unixのシェルから、推論エンジンと
GUIの二つを立ち上げなければならない。これらの起動順序は定まっており、
推論エンジンを立ち上げた後で、GUIを立ち上げなければならない。

\subsection{起動コマンド}

この節で述べられるguidbt, guiの二つのコマンドはHELIC-IIのインストール
ディレクトリの下のbinの中にある。これらのコマンドの生成方法はインストール
マニュアル(INSTALL(.j))を参照のこと。

\subsubsection{推論エンジン}

{\bf コマンド:}
\begin{quote}
guidbt [-port PORTNO]
\end{quote}

{\bf 引数:}
\begin{quote}
\begin{tabbing}
PORTNO \ \ \= \kill
PORTNO \> ソケットのポート番号。\\
\end{tabbing}
\end{quote}

{\bf 詳細:}
\begin{quote}
推論エンジンを起動する。起動するには引数または環境変数HELIC\_HOST\_PORTに
よって、
GUI Processと結ぶソケットのポート番号を指定しておかなければらならない。
そのポート番号はGUIに指定するポート番号と共通でなければならない。

例えばポート番号を9900に指定する場合は、以下のように行なう。

\begin{verbatim}
% setenv HELIC_HOST_PORT 9900
\end{verbatim}

\end{quote}

{\bf 備考:}
\begin{quote}
環境変数によって指定されていない場合は、ポート番号は9000に自動設定される。
このコマンドは、HELIC-IIのGUIを終了させることで自動的に終了する。
\end{quote}


\subsubsection{GUI}

{\bf コマンド:}
\begin{quote}
gui [-host HOSTNAME] [-port PORTNO]
\end{quote}

{\bf 引数:}
\begin{quote}
\begin{tabbing}
HOSTNAME \ \ \= \kill
HOSTNAME \> 推論エンジン Processを起動したマシンのホスト名。\\
PORTNO \> ソケットのポート番号。\\
\end{tabbing}
\end{quote}

{\bf 詳細:}
\begin{quote}
GUI Processを起動する。起動するには推論エンジンが既に起動していなければ
ならない。
起動するにあたって、推論エンジンが動いているマシンのホスト名とソケットの
ポート番号を指定しなければならない。その指定は上記 引数を使う方法の他に
環境変数によっても指定できる。

推論エンジン Processが動いているマシンのホスト名は、環境変数HELIC\_HOST\_NAMEに
よって指定される。
推論エンジン Processと結ぶソケットのポート番号は、環境変数HELIC\_HOST\_PORTに
よって指定される。そのポート番号は推論エンジン起動時に指定するポート番号と
共通でなければならない。

二つの方法で同時に指定されている場合は、
引数による指定が、環境変数による指定よりも優先される。
この二つが指定されていない場合は、エラーウインドウを出してGUIは終了する。

このコマンドが実行されることで画面上にHELIC-IIのGUIの初期ウインドウが
表示される。

{\bf 関連するファイル:}

\begin{quote}
~/.Xdefaults
\end{quote}
\end{quote}

\section{初期ウインドウにおける操作}

HELIC-IIが起動するとこのウインドウがまず開く。
論争ウインドウを開く前に、
この中で知識ベースのロードと論争当事者の割当を行なわなければならない。

このウインドウの起動方法は、「\ref{KH} 起動方法」に詳しく書いてある。
標準的な環境では、
\begin{verbatim}
	% setenv HELIC_HOST_PORT 9900
	% setenv HELIC_HOST_PORT here
	% guidbt &
	% gui
\end{verbatim}
とすれば起動する。

\begin{figure}[htb]
\begin{center}
\epsfile{file=initwin.ps,height=6cm}
\end{center}
\caption{初期ウインドウ}\label{figSW}
\end{figure}

\begin{itemize}
\item ブラウジングエリア
\begin{description}
\item[Loading Status:] 論争を始めるのにロードしなければならない
知識ファイルを示唆する。
\item[Role Assigment Status:] ユーザ、システムのどちらが論争当事者を
担当することになっているかを表示する。
\end{description}
\item アクションエリア
\begin{description}
\item[Loadボタン:] 知識ファイルのロードを行なう。
ファイルロードウインドウ(\ref{FLW}参照)を開く。
\item[Roleボタン:] 論争当事者の担当を決める。
\item[Debateボタン:] 論争ウインドウを開く。ロードと役割設定が終るまで
ボタンは効かない。
\item[Quitボタン:] 全てのウインドウが閉じ、HELIC-IIが終了する。
\end{description}
\end{itemize}

\subsection{HELIC-IIを終了するには}
初期ウインドウの{\sl Quit}ボタンを選択する。

\subsection{知識をロードするには}\label{FLW}
知識をロードするには、初期ウインドウの{\sl Load}ボタンを選択して、
ファイルロードウインドウを開く。

\begin{figure}[htb]
\begin{center}
\epsfile{file=loadwin.ps,height=10cm}
\end{center}
\caption{ファイルロードウインドウ}\label{figFLW}
\end{figure}

\begin{itemize}

\item ファイル種類選択エリア
\begin{description}
\item[Type:] 型定義ファイルを選択する。*.tのファイルのみが
Listフィールドに表示される。
\item[Rule:] ルール定義ファイルを選択する。*.rのファイルのみが
Listフィールドに表示される。型定義ファイルがロードされていないと選択できない。
\item[View:] 半順序定義ファイルを選択する。*.vのファイルのみが
Listフィールドに表示される。ルール定義ファイルがロードされていないと選択できない。
\item[Query:] ゴール定義ファイルを選択する。*.gまたは*.goalのファイルのみが
Listフィールドに表示される。半順序定義ファイルがロードされていないと選択できない。
\item[Command:] コマンドファイルを選択する。*.cのファイルのみがListフィールドに
表示される。
\end{description}

\item ファイル選択エリア
\begin{description}
\item[Filter] Fileに表示するファイルの正規表現。
\item[Directory:] カレントディレクトリにあるディレクトリの一覧が表示される。
\item[List:] カレントディレクトリにあるファイル種類選択エリアで選択された
種類の知識ファイルの一覧が表示される。
\item[Loading File:] ロード対象となっているファイル名が表示される。
直接キーボードからも入力できる。
\end{description}

\item アクションエリア
\begin{description}
\item[Loadボタン:] 選択された知識ファイルのロードを推論部に命じる。
\item[Listボタン:] 現在までにロードされた知識ファイルの
一覧表示ウインドウを開く。

\begin{figure}[htb]
\begin{center}
\epsfile{file=listwin.ps,height=3cm}
\end{center}
\caption{ロードファイル一覧ウインドウ}\label{figLFW}
\end{figure}

\item[Doneボタン:] ロード操作を終了する。ファイルロードウインドウを閉じる。
\end{description}

\end{itemize}

\subsubsection{ディレクトリを移動するには}
ファイルロードウインドウのDirectoryフィールドに表示されているディレクトリを
マウスでダブルクリックすることにより移動します。

\subsubsection{型定義ファイルをロードするには}
ファイルロードウインドウ上部のTypeをクリックすると、Listフィールドには*.t
のファイルのみが表示される。ロードしたいファイルをダブルクリックすれば
ロードされる。

\subsubsection{ルール定義ファイルをロードするには}
ファイルロードウインドウ上部のRuleをクリックすると、Listフィールドには*.r
のファイルのみが表示される。ロードしたいファイルをダブルクリックすれば
ロードされる。

\subsubsection{半順序定義ファイルをロードするには}
ファイルロードウインドウ上部のViewをクリックすると、Listフィールドには*.vの
ファイルのみが表示される。ロードしたいファイルをダブルクリックすれば
ロードされる。

\subsubsection{ゴール定義ファイルをロードするには}
ファイルロードウインドウ上部のGoalをクリックすると、Listフィールドには*.gまたは*.goalの
ファイルのみが表示される。ロードしたいファイルをダブルクリックすれば
ロードされる。

\subsubsection{コマンドファイルを実行するには}
ファイルロードウインドウ上部のCommandをクリックすると、Listフィールドには*.cの
ファイルのみが表示される。実行したいファイルをダブルクリックすれば
実行される。

\subsubsection{今までにロードしたファイルの一覧をみるには}
ファイルロードウインドウの{\sl List}ボタンを選択してロードファイル一覧ウインドウを
開く。

\subsection{論争における役割を設定するには}\label{YSW}

論争における役割を設定するには、初期ウインドウの{\sl Role}ボタンを選択して
役割設定ウインドウを開く。

\begin{figure}[htb]
\begin{center}
\epsfile{file=rolewin.ps,height=5cm}
\end{center}
\caption{役割設定ウインドウ}\label{figYSW}
\end{figure}

\begin{itemize}

\item 役割設定エリア

左で検察の設定を行ない、右で被告の設定を行なう。
\begin{description}
\item[System:] その論争当事者（検察または被告）をシステムが担当し、
自動的に論争を進めるようにする。
\item[User:] その論争当事者（検察または被告）をユーザが担当し、
論争の進行に必要な操作は全てユーザに任せられる。
\end{description}

\item アクションエリア
\begin{description}
\item[Doneボタン:] 現在設定した役割をシステムに登録する。
役割設定ウインドウを閉じる。
\end{description}

\end{itemize}

\subsubsection{検察（被告）をユーザに担当させるには}
役割設定ウインドウの左の列（被告の場合は右）の{\sl User}ボタンをクリックする。

\subsubsection{検察（被告）が自動的に論争するにように設定するには}
役割設定ウインドウの左の列（被告の場合は右）の{\sl System}ボタンを
クリックする。

\subsubsection{現在の設定を登録するには}
役割設定ウインドウの{\sl Done}ボタンを選択する。

\section{論争ウインドウにおける操作}
\begin{quotation}
論争ウインドウは２枚同時に開き、それぞれのウインドウが論争当事者である
検察と被告を表す。検察のウインドウから行なう操作や様々な設定は全て検察に
対して行なわれると解釈する。

論争ウインドウを開くには、型、価値観、ゴール、ルールが全てロードされ、
検察と被告の役割の設定を完了する必要がある。

また論争ウインドウからポップアップに開くウインドウは全て排他的制御の
ウインドウとし、開いている間は論争ウインドウの制御を受け付けない。
論争中は、発言権がある時のみ論争ウインドウはsensitiveになる。
\end{quotation}

\begin{figure}[htb]
\begin{center}
\epsfile{file=debatewin.ps,height=12cm}
\end{center}
\caption{論争ウインドウ}\label{figRW}
\end{figure}

\begin{itemize}

\item 論争設定部\\
論争中は以下のボタンは全てinsensitiveになる。
\begin{description}
\item[Viewボタン:] 価値観を設定する。
\item[Unitボタン:] 使用する知識を設定する。
\item[Goalボタン:] ゴールを設定する。
\item[Startボタン:] 論争を開始する。
\item[Quitボタン:] 論争ウインドウを閉じる。
\end{description}

\item 論争設定ブラウザ部
\begin{description}
\item[Goal エリア:] 現在設定されているゴールを表示する。
\item[View エリア:] 現在設定されている価値観を表示する。
\end{description}

\item 論争操作部
論争中以外は全てinsensitiveであり、論争中も実行可能なコマンドのみが
sensitiveになる。
\begin{description}
\item[Poseボタン:] 現在 論証表示エリアに表示されている論証を相手に通知する。
\item[Noticeボタン:] 現在 論証表示エリアに表示されている自分の論証が
相手の論証よりも優先すると、相手に対して優先通知する。
\item[Cancelボタン:] 現在 論証表示エリアに表示されている自分の主張を取り下げる。
\item[Finishボタン:] 現在 論証表示エリアに表示されている相手の論証について
反論が終ったことを通知する。
\item[Jusitfyボタン:] 論証を正当化する。
\item[Depthボタン:] 主張、反論を生成する際に、相手の反論を何段まで先読みするか
を設定する。
\item[Endボタン:] 論争を強制的に終了する。
\end{description}

\item 論争状態ブラウザ部
\begin{description}
\item[論争履歴エリア:] 現在の論争の状態を表すリストを表示する。
\item[状態表示エリア:] 論争の状態を表示する。
例えば「相手が以下の反論をしてきました」、「相手が人権重視の立場から
以下の主張が優先することを通告してきました。」などが表示される。
\item[争点表示エリア:] 現在表示されている論証が反論している相手の主張の争点を
表示する。
\item[論証表示エリア:] 論証を表示する領域。論証である証明木を構成する各ルールの
Unifyされた結論(中間命題)を、その参照関係によりインデント付けて表示している。
\end{description}

\item{論証ブラウザ操作部}
\begin{description}

\item[Backwardボタン:] 現在 論証表示エリアに表示されている論証の反論対象である
論証を表示させる。
\item[Forwardボタン:] Backwardボタンで移動した場合、このボタンを選ぶことで
直前のBackwardで移動する前の論証に戻る。
現在 論証表示エリアに表示されている論証への反論のある一つへ戻る。
\item[Nextボタン:] 現在 論証表示エリアに表示されている論証と同じ争点について
争っているが反論がある場合それに進む。
\item[Previousボタン:] 現在 論証表示エリアに表示されている論証と同じ争点について
争っているが反論がある場合それに進む。
Nextボタンとは逆の順に表示される。
\item[Foucsボタン:] 現在論争のFocusが当たっている論証(Focus論証)にjumpする。
\item[ClaimListボタン:] 自分及び相手の過去の主張を検索する。
\item[Jumpボタン:] 主張IDを入力することで、指定した論証を表示させる。
\item[Explainボタン:] 現在表示している論証の自然言語による説明文を
表示させる。
\item[formボタン:] 論証表示エリアに表示する中間命題の表示形式を指定する。
表示形式にはH項による表現と自然言語による説明分の二通りが用意されている。
\end{description}

\end{itemize}

ロードと、論争の役割設定を終えていないと{\sl Debate}ボタンは
sensitiveにはならない。

\subsection{論争ウインドウを閉じるには}
{\sl Quit}ボタンを選択する。

\subsection{価値観を設定するには}\label{KSW}

価値観を設定するには、設定したい論争当事者の論争ウインドウの{\sl View}ボタンを
選択して価値観設定ウインドウを開く。

\item[View Candidateボタン:] 価値観候補選択ウインドウを呼び出して、

すでに用意されている価値観候補を指定して価値観を設定する場合は、

\subsubsection{価値観に判断基準を追加するには}
今ある価値観に判断基準を追加するには、{\sl Standpoint}ボタンを選択して
判断基準選択ウインドウを開く。
そこには定義されている全ての判断基準が表示されている。
判断基準の名前をダブルクリックすることで、判断基準を選択し、
価値観に追加することができる。選択された判断基準は価値観の中で
最後に追加される。

\subsubsection{価値観から判断基準を削除するには}
価値観表示エリア中の削除したい判断基準をダブルクリックすることで削除できる。

\subsubsection{価値観の順序を変更するには}
{\sl Order}ボタンを選択して、価値観順序変更ウインドウを開く。
価値観順序変更ウインドウの左に現在の順序が表示される。ユーザの希望する順に
左の判断基準をダブルクリックしていけばその順に右のエリアに判断基準が上から
表示される。全ての左の判断基準の選択が終れば価値観順序変更ウインドウは
自動的に閉じ、新しい順序の価値観が価値観表示エリアに表示される。

\subsubsection{価値観をクリアするには}
{\sl Clear}ボタンを選択する。

\subsubsection{修正した価値観を登録するには}
{\sl Done}ボタンを選択すると価値観表示エリアに表示されている価値観が
論争当事者の価値観として登録される。

\subsubsection{価値観修正作業を途中でやめるには}
{\sl Cancel}ボタンを選択すると、価値観変更ウインドウを開いてからの修正作業が
破棄されて価値観変更ウインドウが閉じる。価値観に変更は起こらない。

\subsection{論争を行なうには}

\subsubsection{論争を始めるには}
論争ウインドウの{\sl Start}ボタンを選択する。ただし、選択の前に
検察と被告双方の価値観、使用知識と検察のゴールの設定を行なわなければならない。
検察をユーザが担当している場合は、Startの後に主張選択操作をおこなう。
この操作に関しては「\ref{SWS} 主張を選択するには」を参照のこと。

\subsubsection{論争を終えるには}
論争ウインドウの{\sl Quit}ボタンを選択する。

\subsubsection{主張を選択するには}\label{SWS}
検察がユーザ担当の場合、論争の最初と検察の最初の主張に被告が反論終了を
通告した時に、ユーザは初期主張（検察のゴールを導く主張）を選択しなければ
ならない。この時、主張選択ウインドウが開く。

\begin{figure}[htb]
\begin{center}
\epsfile{file=argslctwin.ps,height=6cm}
\end{center}
\caption{主張選択ウインドウ}\label{figSSW}
\end{figure}

このウインドウには、導出された初期主張の結論のリストが表示されている。
左の$>0:!0:<1$の意味は「\ref{RIHM} 論証一覧表示の見方」を参照のこと。
リストの中で見たい主張の結論をマウスでダブルクリックして選択すると、
主張選択ウインドウは閉じ、論証表示エリアに選択した主張（論証）が表示される。

\subsubsection{相手に論証を主張するには}
相手に初期主張または反論を主張するには、相手に論証を送付する必要がある。
そのためには、以下の二つのことをあらかじめ行なわなければならない。
\begin{itemize}
\item 論証表示エリアに送付したい論証を表示すること\\
送付したい論証を表示させるには「\ref{RBSS} 論証ブラウザの操作の仕方」を
参照のこと。
\item 反論を主張する時は、送付する論証が有効でなければならない。\\
有効とは、検察の場合、相手の論証よりも優位なことであり、被告の場合は、
相手の論証よりも優位か無関係であることである。\\
論証を優位にするには、「\ref{RY} 論証を優位にするには」を参照のこと。
\end{itemize}
この条件が満たされると、論争操作部の{\sl Pose}ボタンがsensitiveになる。
{\sl Pose}ボタンを選択することで相手に論証は送付され主張したことになり、
発言権は相手に移る。

\subsubsection{通知された相手の論証の反論を選ぶには}

相手から主張または反論を通知してくると、自分の論証表示エリアに
通知された相手の主張が表示される。
相手の主張の中から反論したい争点を選ぶ。どの争点に反論があるかは、
争点の左の数字によってわかる\footnote{詳しくは「\ref{RHM} 論証表示の見方」
を参照。}。
争点をダブルクリックして反論選択ウインドウを開く。

\begin{figure}[htb]
\begin{center}
\epsfile{file=cargwin.ps,height=6cm}
\end{center}
\caption{反論選択ウインドウ}\label{figHSW}
\end{figure}

このウインドウには、反論として争点の逆を導く論証の結論のリストが
表示されている。
左の$>0:!0:<1$の意味は「\ref{RIHM} 論証一覧表示の見方」を参照のこと。
リストの中で見たい反論の結論をマウスでダブルクリックして選択すると、
反論選択ウインドウは閉じ、論証表示エリアに選択した反論（論証）が表示される。


\subsubsection{通知された相手の論証に対して優先通告するには}\label{NT}

相手の反論している自分の過去の主張が、相手の反論よりも強い（被告の場合は
敗けない）場合、自分の主張の優位を相手に宣言することで相手の反論を封じることが
できる。このためには、以下の条件を満たさなければならない。

\begin{itemize}
\item 論証表示エリアに優位を主張したい自分の論証を表示する。\\
相手の反論がまず表示されているので{\sl Backward}ボタンで一つ戻る。
\item 自分の反論が相手の反論よりも強い（被告の場合は敗けない）こと。\\
論証を優位にするには、「\ref{RY} 論証を優位にするには」を参照のこと。
\end{itemize}
この条件が満たされるていれば、論争操作部の{\sl Notice}ボタンが
sensitiveになっている。
なっている場合は、{\sl Notice}ボタンを選択すると判断基準選択ウインドウが開く。
\newpage
\begin{figure}[htb]
\begin{center}
\epsfile{file=spslctwin.ps,height=6cm}
\end{center}
\caption{判断基準選択ウインドウ}\label{figHKSW}
\end{figure}

ウインドウには、相手の反論よりも自分の論証が有利であるとの根拠となる
判断基準または判断基準の組合せのリストが表示されている。
その中で相手に自分が優位であることの根拠として通知したいと思う判断基準を
ダブルクリックすることで、相手への優先通知の作業は終了する。

ただし、エージェントが被告で論証の関係が無関係の場合は、
判断基準選択ウインドウの作業を経ずに相手への優先通知の作業は終了し、
発言権は相手に移る。


\subsubsection{相手の優先通告に対して自分の優先を通知するには}

相手が無効を通知したこちらの反論を論争表示エリアに表示し、
相手に優先通知を行なう。優先通知の行ない方は「\ref{NT} 通知された相手の論証に
対して優先通告するには」を参照のこと。
なお、この場合は発言権は相手に移らず、相手の主張に対して別の反論を探すことに
なる。


\subsubsection{自分の主張を放棄するには}

相手の反論または優先通告に対して、有効な反論や優先通告の理由が見つからない時は
自分の主張を放棄しなければならない。放棄するには自分の主張を論争表示エリアに
表示して{\sl Cancel}ボタンを選択する。


\subsubsection{相手の論証に対する反論の終了を宣言するには}

相手の論証に対して、それ以上反論がないもしくは反論をしないと決めた場合、
相手に宣言して相手に他の論証を出すように要求できる。\\
終了宣言のためには、反論を終了したい相手の論証を論証表示エリアに表示して
{\sl Finish}ボタンを選択する。


\subsubsection{論証を優位にするには}\label{RY}

現在表示している論証を優位にするために価値観を補強することができる。
{\sl Justify}ボタンを選択すると、現在表示している自分の論証が焦点となっている
相手の論証よりも有利になるように価値観に追加すべき判断基準を検索する。
追加すべき判断基準の組合せが見つかった場合は、価値観変更示唆ウインドウが
開かれ、そこに表示される判断基準の組合せのリストの中からユーザが適当と
考えるものを選択する。選択の結果、価値観が変更され論証表示エリアの内容が
更新される。

\begin{quote}
\begin{figure}[htb]
\begin{center}
\epsfile{file=viewchgwin.ps,height=6cm}
\end{center}
\caption{価値観変更示唆ウインドウ}\label{figKHSW}
\end{figure}

左のリストは追加すべき判断基準の組合せを表している。左のリストの中から
任意の判断基準をクリックすることで選択できる。選択された判断基準を
追加した場合の価値観の内容が右のリストに表示される。その内容が満足であれば
{\sl Done}ボタンを選択することで価値観の変更を登録でき、
価値観変更示唆ウインドウは閉じる。
\end{quote}

価値観の変更は、定義された判断基準の組合せの中で検索されるため、
希望する論証の優先関係を満たす新しい価値観が見つからないこともある。
また、過去に自分が行なった優先通告と矛盾する優先関係を含む新しい価値観は
候補とはならない。そのため、{\sl Justify}ボタンを選択しても適当な価値観が
見つからないことはある。その場合は該当する価値観がないというエラーウインドウが
開く。この場合は論証を優位にすることができないので、他の反論を探すか
論証を放棄するなどの対策が必要になる。


\subsubsection{先読みの深さを変更するには}

論争の過程ではDefeasible Reasoningの枠組で主張や反論を生成している。
Defeasible Reasoningの中では、導出された推論木に対する反論を導出し、
さらにその反論も導出するというように再帰的に反論を全て求めようとしている。
この計算量を減らすために反論のさらに反論を導出するといった論争の先を読む
段数を制限することができる。\\
{\sl Depth}ボタンを選択することで、先読み設定ウインドウが開く。
検察、被告それぞれの先読みの段数を入力してDoneボタンを選択することで
設定される。段数が１とは自分が選ぶべき論証の１段先の反論まで導出する
ということである。

表示されている論証のトップルールの方が優先度が高いということを意味し、
後者は二つのルールの間に優先関係がないことを意味する。

それ以降の数字が頭に降られた行は、論証を証明木の形で表している。
それぞれの行は論証の中で使われた中間ルールによって導かれた中間命題である。
変数は全てUnifyされた形で表現される。
\newpage
一つを例にとり、さらに詳しく説明する。

\begin{figure}[htb]
\begin{center}
\begin{verbatim}
       子情報	    中間命題
=================================================================
       !  1(0)      故意あり(a_object=人間[name=>"
\end{verbatim}
\end{center}
\caption{論証表示の中間命題の例}\label{figRHCR}
\end{figure}

子情報はこの争点に対する子に関する情報を示したものである。
最初の$!$は、この争点を導くルールと、この争点に対して複数ある子の
トップルールとの関係の情報を表したものである。
種類としては$>,!,<$があり、$>$は全ての子に対するトップルール関係が強い
争点、$!$は強いのと無関係なトップルール関係がある争点、$<$は1つでも弱
いものがある争点をあらわす。

次の$1(0)$は、最初の数字が子の数を表す。次の括弧内の数字は論争が
終了した子の数を表す。なお、ここでいう論争終了とは、検察,被告両
方でお互いの主張が優位であることをnoticeコマンドにより通知した場
合とfinishコマンドにより相手から自分の主張した論証について論争を
終了したことを通知された場合を指す。

中間命題はルールの帰結部に相当する。
各行の中間命題に空白がはいっていて1段差があるのは、1段差ある
ものにより、段差がないものが導かれたことをあらわす。

\subsubsection{論証一覧表示の見方}\label{RIHM}

反論一覧表示ウインドウ、論証一覧表示ウインドウにて表示される複数の論証を
表示する形式について説明する。

以下に反論一覧表示の例を示す。

\begin{figure}[htb]
\begin{center}
\begin{verbatim}
Arg ID: p0
Issue Pos: 13
Consequence: 故意あり(a_object=人間
RuleName: 刑235大塚説
Num Of Counter: 1
0 : *  !  >:0!:1<:0 -故意あり(a_object=人間
\end{verbatim}
\end{center}
\caption{反論一覧表示の例}\label{figHIHR}
\end{figure}

\begin{description}

\item[Arg ID:] 親論証ID。
\item[Issue Pos:] 親論証の争点番号。\\
この子一覧表示は親論証のどの争点に対するものなのかを表す。
\item[Consequence:] 親論証の争点番号に対応する争点を導くルールの実行部。
\item[RuleName:] 親論証の争点番号に対応する争点を導くルールの名前。
\item[Num Of Counter:] 親論証の争点番号に対応する争点に対する反論の数。
\item[0:] 子番号。\\
$*$は既にposeコマンドにより反論ずみの場合であり、まだ反
論していない場合はなにも表示されない。\\
$!$は親論証の争点とこの子番号に対応する論証との
TopRule関係を表していて、種類としては$>,!,<$がある。それぞ
れ、親に対して子が弱い,無関係,強いである。\\
$>:0!:1<:0$はこの子番号に対応する論証に対する子との
TopRule関係であり、強い(\(>\)),無関係(!),弱い(\(<\))がいくつある
かを示したものである。

\end{description}

\subsubsection{反論先の論証を見るには}
そのためにはBackwardボタンを使う。
Backwardボタンを選択することで、論証表示エリアに表示されている論証が
反論している論証が表示される。

\subsubsection{反論を見るには}
そのためには現在表示されている論証の中からまず調べたい中間命題を争点として
選ぶ。
論証表示エリアに表示された中間命題をマウスでダブルクリックすることで
中間命題は選択される。
中間命題を選択することで、その中間命題を争点とする反論の一覧が表示される。

\begin{figure}[htb]
\begin{center}
\epsfile{file=cargwin.ps,height=6cm}
\end{center}
\caption{反論選択ウインドウ}
\end{figure}

このウインドウには、反論の結論のリストが表示されている。
その中で見たい反論の結論をマウスでダブルクリックして選択する。
その結果、反論選択ウインドウは閉じ、論証表示エリアに選択された反論が
表示される。

この他に、Forwardボタンによっても反論へ移動できる。
この場合は反論の選択操作が省略され、
直前のBackwardボタンでの移動の移動元の論証が論証表示エリアに表示される。
Forwardボタンは、Backwardボタンを使って親を見た後に元の論証へ戻るのに使うのが
一般的である。

\subsubsection{同じ争点について他の反論を見るには}

そのためには、nextボタンかpreviousボタンを使う。
nextボタンかpreviousボタンを選択することで同じ争点について争う他の論証が
論証表示エリアに表示される。
nextボタンとpreviousボタンは論証の表示順序が違うので、
nextボタンの移動の後にpreviousボタンを選択すれば元の論証に戻れる。


\subsubsection{論争の焦点になっている論証を見るには}

{\sl Focus}ボタンを選択する。


\subsubsection{論証IDの分かっている論証を表示するには}

{\sl Jump}ボタンを選択して、論証ID指定ウインドウを開き、論証IDを入力して
リターンを入力すると、論証IDに対応する論証が表示される。
論証IDは主張済みの論証にしか付与されていないことに注意すること。


\subsubsection{過去の主張を検索するには}

{\sl ClaimList}ボタンを選択すると、主張一覧ウインドウが表示される。

\begin{figure}[htb]

\end{center}
\caption{主張一覧ウインドウ}\label{figSIW}

左が検察の主張で、右が被告の主張である。
表示形式は論証一覧表示と同様である(\ref{RIHM} 参照)。
見たい主張をダブルクリックすることで、その主張が表示される。


\subsubsection{論証表示を自然言語にするには}

{\sl Form}ボタンを選択すると、表示形式選択ウインドウが表示される。

\section{DRSウインドウにおける操作}

\begin{quotation}
DRS機能は、論争と異なり一つの価値観で問題を分析するためにある。
先読みの深さを$-1$にすることで全解探索を行なうことができる。

DRS(Defeasible Reasoning System)ウインドウは初期ウインドウから開かれる。
DRS(Defeasible Reasoning System)ウインドウは基本的に論争ウインドウから
論争操作部を除いたものと同じである。
そのためDRSウインドウにおけるゴール・価値観・使用知識の設定方法は
「論争ウインドウにおける操作」を参照すること。

DRSウインドウを開くには、型、価値観、ゴール、ルールのロードが
完了している必要がある。

DRSウインドウと論争ウインドウは同時に開くことはできない。
\end{quotation}

\begin{figure}[htb]
\begin{center}
\epsfile{file=drswin.ps,height=12cm}
\end{center}
\caption{DRSウインドウ}\label{figRW}
\end{figure}

\begin{itemize}

\item DRS設定部\\
\begin{description}
\item[Viewボタン:] 価値観を設定する。
\item[Unitボタン:] 使用する知識を設定する。
\item[Goalボタン:] ゴールを設定する。
\item[Solveボタン:] 推論を開始する。
\item[Quitボタン:] DRSウインドウを閉じる。
\end{description}

\item DRS設定ブラウザ部
\begin{description}
\item[Goal エリア:] 現在設定されているゴールを表示する。
\item[View エリア:] 現在設定されている価値観を表示する。
\end{description}

\item DRS状態ブラウザ部
\begin{description}
\item[論証表示エリア:] 論証を表示する領域。論証である証明木を構成する各ルールの
Unifyされた結論(中間命題)を、その参照関係によりインデント付けて表示している。
\end{description}

\item{論証ブラウザ操作部}
\begin{description}
\item[Backwardボタン:] 現在 論証表示エリアに表示されている論証の反論対象である
論証を表示させる。
\item[Forwardボタン:] Backwardボタンで移動した場合、このボタンを選ぶことで
直前のBackwardで移動する前の論証に戻る。
現在 論証表示エリアに表示されている論証への反論のある一つへ戻る。
\item[Nextボタン:] 現在 論証表示エリアに表示されている論証と同じ争点について
争っているが反論がある場合それに進む。
\item[Previousボタン:] 現在 論証表示エリアに表示されている論証と同じ争点に
ついて争っているが反論がある場合それに進む。
Nextボタンとは逆の順に表示される。
\item[Explainボタン:] 現在表示している論証の自然言語による説明文を
表示させる。
\item[formボタン:] 論証表示エリアに表示する中間命題の表示形式を指定する。
表示形式にはH項による表現と自然言語による説明分の二通りが用意されている。
\end{description}

\end{itemize}

\subsection{DRSウインドウを開くには}
初期ウインドウの{\sl DRS}ボタンを選択すると開く。ただし、必要なファイルの
ロードを終えていないと{\sl DRS}ボタンはsensitiveにはならない。

\subsection{DRSウインドウを閉じるには}
DRSウインドウの{\sl Quit}ボタンを選択する。

\subsection{推論を行なうには}

DRSウインドウの{\sl Solve}ボタンを選択する。ただし、選択の前に
価値観、使用知識、ゴールの設定を行なわなければならない。
推論結果は論証表示エリアに表示される。
論証ブラウザの操作方法は、「論証ブラウザの操作の仕方」を参照すること。

\section{制限事項}

'95/4配布のバージョンでは以下の機能が実現されていません。

\begin{itemize}
\item 自然言語によって論証を表示する機能
\item 論争後に過去の主張を参照するブラウズ機能
\end{itemize}
