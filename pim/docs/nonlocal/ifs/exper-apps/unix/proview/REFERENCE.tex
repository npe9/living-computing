\chapter{言語仕様}
\section{文法}
この言語の文法を、BNFを用いて記述すると以下のようになる。

\begin{verbatim}
<statement>  ::= <expression> ";"
               | <message> ";"
<expression> ::= <expression> <message>
               | <object> <message>
<object>  ::= <object> member_selector
            | <article> class_name
            | variable
            | literal
<article> ::= "a"
            | "an"
<message> ::= message_selector
            | message_selector <argument>
<argument> ::= "(" expression ")"
            |  <coordinate>
            |  <list>
            |  variable
            |  literal
<coordinate>::= "{"number "," number "," number"}"
<list>   ::= "[" <argument> [ "," <argument>] "]" 
\end{verbatim}

\bigskip
\begin{tabular}{c|l}
\hline
member  & radius depth top bottom height division \\
selector& string font size width style points color \\ \hline
message & is draw drawall hide hideall wire wireall \\
selector& transform moves location rotate rotation \\
	& from to alpha append bind cdr car \\
        & magnify antialiases into up push pop \\
        & smooths nurbs shines colors speculer \\
        & insert element value delete quit sync \\ \hline
\end{tabular}
\bigskip

文は、メッセージと、そのメッセージの送り先である変数で構成される。メッ
セージを実行した結果、値を返すようなメッセージの場合、返された値を変数
に代入、あるいは引数としてメッセージで渡すことができる。記述例を以下に
示す。

\begin{verbatim}
   Sphere is a sphere;
   Sphere moves{1,2,3};
   Sphere color is Red;
   Text is a text;
   Text color is Sphere color ; 
   Text moves (Sphere location); # Sphereの位置にTextを移動する。
\end{verbatim}

この例ではmovesメッセージで設定したSphereの座標位置\{1,2,3\}へTextを
移動させている。

\section{変数(variable)}

変数名は、予約語を除く全ての文字列を指定することが可能である。変数の指
定方法としては、絶対位置を指定する方法と、カレントオブジェクトからの相
対位置を指定する方法が用意されている。相対位置指定および、絶対位置を指
定する例を以下に示す。

\bigskip
\begin{verbatim}
   X is a group;
    into X;
   SphereA is a sphere;    # X SphereA is a sphere;
   SphereA color is :Red;  # X SphereA radius is Red
   SphereA draw;
   SphereB is a sphere;    # X SphereB is a sphere;
   SphereB color is :Red;  # X SphereA radius is Red;
   SphereB draw;
   up;
\end{verbatim}

上の例では、SphereA,SphereBの変数指定が、グループオブジェクトXからの相
対位置指定であり、メンバーcolorへのマテリアルオブジェクトの参照を代入
する際の:Redがルートからの絶対位置指定となっている。\\メンバーの値の参
照、書き換えは、以下のように行なう。

\begin{verbatim}
   X is a sphere;
   X color is Red;
   Y is a sphere;
   Y color is Green; 
   Y color is X color; 
\end{verbatim}

上の例では、 Yの色はXのcolorというメンバーが参照しているオブジェクトを
参照することになる。

\subsection {ライトオブジェクト(light)}
環境光のオブジェクトである。マテリアルオブジェクトが、オブジェクト自身
の色を付加するのに対し、環境光の光線の色、光源の位置を指定するオブジェ
クトである。ライトオブジェクトの表示システム内での個数は最大8個である。
生成の例を以下に示す。

\begin{verbatim}
 Light0 is a light;
 Light0 colors{0.2,0.2,0.2};
 Light0 moves{10,10,-10};
 Light0 bind;
\end{verbatim}

\bigskip
\noindent
このオブジェクトが実行可能なメッセージを以下に示す。\\
\begin{messagetable}
moves \{x座標の値,y座標の値,z座標の値\} \index{moves} & 光源の位置を設
定する。\\ \hline
colors \{redの値,greenの値,blueの値\} \index{colors} & 光線のRGB成分を
設定する。\\ \hline
bind \index{bind} & 環境光の情報をシステムに登録する。\\ \hline
\end{messagetable}

\subsection {システムメッセージ}
システムに対しての操作について述べる。
\subsubsection{syncメッセージ}
非同期表示モードの同期をとるためのメッセージを用意した。
このメッセージの送り先は何を指定しても良い。
このメッセージは、表示システムが-RTオプションで起動された場合には、何
の処理も行なわれない。もし、-RTオプションを付加せずに表示システムを、
起動した場合では、文の実行を中断して、表示の更新を行なう。実行例を以下
に示す。
\begin {itemize}
\item []  sync;
\end {itemize}
\subsubsection{quitメッセージ}
スクリプトの制御により、表示プログラムの終了をさせるために用意したメッセージである。
\begin {itemize}
\item []  quit;
\end {itemize}

\chapter{オブジェクトのコピーと参照}
\section{オブジェクトのコピー}
変数の内容のコピーの方法は、
\begin {itemize}
\item [] X = Y;
\end {itemize}
である。コピーの対象であるデータ型を以下に示す。
\begin{enumerate}
\item 球、円筒などのグラフィックオブジェクト
\item グループオブジェクト
\item リストオブジェクト
\item 数オブジェクト
\item 文字列オブジェクト
\item 位置情報オブジェクト
\end{enumerate}
グラフィックオブジェクトのメンバー、座標情報、角度情報については、参照
をコピーするのみとしている。
\begin {itemize}
\item [] Xlist is [{0,0,2},{0,0,3},{0,0,4}]; 
\item [] X is a line;
\item [] X color is Red;
\item [] X points is Xlist;
\item [] X draw;
\item [] X0 = X;
\end {itemize}
上の例ではlineオブジェクトをコピーしているが、Xのメンバーである
pointsが保持しているリストXlistのコピーは行なわれない。また、グループ
オブジェクトのコピーを行なった場合は、グルーピングされているグラフィックオブジェク
トのコピーも同時に行なう。

\section{オブジェクトの参照}
ある変数の内容を他の変数名で参照する場合、以下のように記述する。
\begin {itemize}
\item [] X is Y;
\end {itemize}
例えば、二つの球を描かせ、その二つの球を円筒で結ぶように描画させるには、
以下のように記述すれば良い。
\begin{itemize}
\item[] Sphere0 is a sphere;
\item[] Sphere0 color is Red;
\item[] Sphere0 moves{1,1,1};
\item[] Sphere1 = Sphere0;
\item[] Sphere1 moves{3,3,3};
\item[] Cylinder is a cylinder0;
\item[] Cylinder color is Yellow;
\item[] Cylinder top is 0.3;
\item[] Cylinder bottom is 0.3;
\item[] Cylinder from (Sphere0 location);
\item[] Cylinder to (Sphere1 location);
\item[] Cylinder draw;
\end{itemize}
