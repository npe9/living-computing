# ICL 2900 series

The ICL 2900 series was a family architecture built around high-level
operating-system and language support. The book emphasizes its virtual
addressing, protection, instruction-set organization, memory hierarchy, and
multiprogramming as examples of a family-level design space.

Bluespec implementation: bsv/ (not started).

See [`plan.md`](plan.md) and [`docs/README.md`](docs/README.md). The initial
source is Chapter 17, printed p. 251, of *Computer Structures: Principles and
Examples* (1982).
