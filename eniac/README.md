# ENIAC (1945)

Eckert & Mauchly, Moore School, U. Penn. First general-purpose electronic computer. Decimal (ring counters), 20 accumulators of 10 digits, ~18,000 valves. Originally programmed by cabling; converted in 1948 to a stored-program style (function tables as instruction memory).

Bluespec implementation: `bsv/` (not started).

Sources: *Report on the ENIAC* (1946); Haigh, Priestley, Rope, *ENIAC in Action*.
