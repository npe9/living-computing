# DEC PDP-11 (1970)

Gordon Bell, Harold McFarland, DEC. 16-bit minicomputer; orthogonal instruction set with 8 general registers (PC and SP among them), 8 addressing modes, byte addressing, memory-mapped I/O on the Unibus. Birthplace of UNIX and C.

Bluespec implementation: `bsv/` (not started).

Sources: *PDP-11/20 Processor Handbook* (1969); *PDP-11 Architecture Handbook*.
