# Ferranti / Manchester Atlas (1962)

Tom Kilburn, Manchester University with Ferranti. Commissioned Dec 1962; arguably the most powerful computer in the world at the time. First virtual memory (paging, one-level store, with associative page registers), the Supervisor (first recognisable OS), extracodes (trap-based software instructions), pipelined 48-bit arithmetic, 128 B-line index registers, 96K words of core + 96K drum in the London/Chilton configuration.

Bluespec implementation: `bsv/` (not started).

Sources: Kilburn et al., "One-Level Storage System" (IRE Trans. EC-11, 1962); *Ferranti Atlas Programming Manual*; Lavington, *A History of Manchester Computers*.
