# Cray-1 (1976)

Seymour Cray, Cray Research. First successful vector supercomputer: 64-bit words, eight 64-element vector registers, chaining, 12.5 ns clock, 160 MFLOPS peak, freon-cooled C-shaped frame.

Bluespec implementation: `bsv/` (not started).

Sources: *Cray-1 Computer System Hardware Reference Manual* (2240004); Russell, "The CRAY-1 Computer System" (CACM 1978).
