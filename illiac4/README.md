# ILLIAC IV

ILLIAC IV was an array processor organized around many processing elements
that applied the same operation to distributed data. Its architecture
illustrates array parallelism, processor control, memory organization, and
the tradeoffs between parallel throughput and communication structure.

Bluespec implementation: bsv/ (not started).

See [`plan.md`](plan.md) and [`docs/README.md`](docs/README.md). The initial
source is Chapter 20, printed p. 306, of *Computer Structures: Principles and
Examples* (1982).
