# C.mmp/Hydra experimental multiprocessor

The C.mmp was a shared-memory multiprocessor built from multiple PDP-11-like
processors. Its Hydra operating system provided protected processes,
interprocessor communication, recovery mechanisms, and a general-purpose
programming environment while allowing processors to be isolated after
failures.

Bluespec implementation: bsv/ (not started).

See [`plan.md`](plan.md) and [`docs/README.md`](docs/README.md). The initial
source is Chapter 22 of *Computer Structures: Principles and Examples* (1982).
