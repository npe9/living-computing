# Texas Instruments TMS 1000

The TMS 1000 was a monolithic microcomputer integrating a processor,
read-only program memory, data memory, and I/O for calculator and control
applications. Its fixed-function, microprogrammed organization illustrates
the cost and capability tradeoffs of putting an entire small system on one
chip.

Bluespec implementation: bsv/ (not started).

See [`plan.md`](plan.md) and [`docs/README.md`](docs/README.md). The initial
source is Chapter 34, printed p. 587, of *Computer Structures: Principles and
Examples* (1982).
