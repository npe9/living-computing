# IBM System/38

The IBM System/38 was a business computer with a high-level machine
architecture. Hardware and microcode supported queue-driven task management,
record-level data management, object-oriented memory management, protection,
and a large virtual address, placing part of the traditional operating-system
interface below the programmer-visible level.

Bluespec implementation: bsv/ (not started).

See [`plan.md`](plan.md) and [`docs/README.md`](docs/README.md). The initial
source is Chapter 32, printed p. 533, of *Computer Structures: Principles and
Examples* (1982).
