# IBM 1401 (1959)

Fran Underwood, IBM. Most widely installed computer of the early 1960s (>10,000). Variable-length decimal character machine: 6-bit BCD characters with word-mark bit, 1.4K–16K characters core, 1403 chain printer.

Bluespec implementation: `bsv/` (not started).

Sources: *IBM 1401 Data Processing System Reference Manual* (A24-1403).
