# STARAN associative array processor

STARAN was an associative array processor that searched and operated on many
data words in parallel rather than treating memory as a purely sequential
store. Its associative matching, array operations, and specialized control
illustrate a processing model distinct from conventional scalar von Neumann
machines.

Bluespec implementation: bsv/ (not started).

See [`plan.md`](plan.md) and [`docs/README.md`](docs/README.md). The initial
source is Chapter 21 of *Computer Structures: Principles and Examples* (1982).
