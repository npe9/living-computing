# ARPA Interface Message Processor

The ARPA Interface Message Processor (IMP) was the autonomous packet-switching
node of the ARPANET. It stored and forwarded messages, segmented them into
packets, routed traffic, checked errors, controlled flow, and isolated host
computers from subnet operation.

Bluespec implementation: bsv/ (not started).

See [`plan.md`](plan.md) and [`docs/README.md`](docs/README.md). The initial
source is Chapter 24, printed p. 403, of *Computer Structures: Principles and
Examples* (1982).
