# Berkeley RISC I (1981)

Patterson & Séquin, UC Berkeley. Reduced Instruction Set Computer: 31 instructions, register windows (78 registers), single-cycle execution, load/store. With Stanford MIPS (Hennessy, 1981–83) it began the RISC era; direct ancestor of SPARC.

Bluespec implementation: `bsv/` (not started).

See [`plan.md`](plan.md) for the staged reproduction plan and
[`docs/README.md`](docs/README.md) for the local primary-source inventory.

Sources: Patterson & Séquin, "RISC I: A Reduced Instruction Set VLSI Computer" (ISCA 1981).
