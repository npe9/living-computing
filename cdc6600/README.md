# CDC 6600 (1964)

Seymour Cray & Jim Thornton, Control Data. First supercomputer proper: 60-bit words, 10 parallel functional units with the scoreboard for out-of-order issue, 10 peripheral processors (barrel), 3 MFLOPS. Roughly 3× Stretch.

Bluespec implementation: `bsv/` (not started).

See [`plan.md`](plan.md) for the staged reproduction plan and
[`docs/README.md`](docs/README.md) for the local primary-source inventory.

Sources: Thornton, *Design of a Computer: The Control Data 6600* (1970); *CDC 6600 Reference Manual*.
