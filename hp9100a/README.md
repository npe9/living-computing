# Hewlett-Packard 9100A

The HP 9100A was an early programmable desktop calculator. Its
microprogrammed implementation provided arithmetic, scientific functions,
storage, and programmable control in a compact system intended for engineers
and scientists rather than batch data processing.

Bluespec implementation: bsv/ (not started).

See [`plan.md`](plan.md) and [`docs/README.md`](docs/README.md). The initial
source is Chapter 48, printed p. 787, of *Computer Structures: Principles and
Examples* (1982).
