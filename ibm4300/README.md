# IBM 4300 series

The IBM 4300 series was part of IBM's planned compatible range descended from
System/360 and System/370. The book treats it as an example of preserving a
programming architecture while changing implementation scale, memory
technology, storage organization, and performance.

Bluespec implementation: bsv/ (not started).

See [`plan.md`](plan.md) and [`docs/README.md`](docs/README.md). The initial
source is Chapter 52 of *Computer Structures: Principles and Examples* (1982).
