# AMD Am2900 bit-sliced processor family

The Am2900 family was a set of bipolar bit-slice components for constructing
custom processors. The Am2901 supplied an ALU and register slice; Am2903,
Am2909, and Am2910 components extended register and microsequencer capability.
The book uses these parts to show microprogrammed implementations, including a
PDP-8 implementation.

Bluespec implementation: bsv/ (not started).

See [`plan.md`](plan.md) and [`docs/README.md`](docs/README.md). The initial
sources are Chapters 13–15 of *Computer Structures: Principles and Examples*
(1982).
