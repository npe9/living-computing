# Golden 009 — `ADDI`, the interlocked fetch-add-store

Image (8 bytes):

```text
70a283fd
00030008
```

Reference pre-state as in 007.  `MOV $5,R8` is the one-parcel
`(0x1C<<10)|(5<<5)|2 = 0x70a2`; `ADDI $3,R8` is the three-parcel
`0x8000|(0x03<<8)|(0xF<<4)|0xD = 0x83fd` with a 16-bit source field
`0x0003` and destination field `0x0008` (Tables 1-18, p. 1-24; p. 3-6).

p. 3-6 gives the operation:

```text
hidden = dst
dst += src
Acc = hidden
```

with "The original value of `dst` is placed in the accumulator" and
"The PSW carry and overflow bits are not affected by ADDI."  The source
is 3 and the destination at `SP+8 = 0x108` is 5, so the destination
becomes 8 and the accumulator at `CSP+4 = 0x104` (p. 1-7, Figure 1-4)
becomes the old value 5.  The fixed one-write HRI line carries the
instruction's primary destination store; the accumulator save is a
second architectural write that the line cannot show (README choice
26).  The model applies both to memory.

L01. `HRI pc=0000 insn=70a20000 sp=00000100>00000100 msp=00000180>00000180 we=1 addr=00000108 data=00000005 mask=0f trap=0 cyc=1`
Cycles: 1 — `MOV` is 1 in Table 4-32 (p. 4-3).
Source: p. 3-32, Table 4-32 p. 4-3.

L02. `HRI pc=0002 insn=83fd0003 sp=00000100>00000100 msp=00000180>00000180 we=1 addr=00000108 data=00000008 mask=0f trap=0 cyc=2`
Cycles: 2 — Table 4-32 (p. 4-3) prints `ADDI` as 2 (the table prints the
mnemonic as `ADD1`; p. 3-6 and Table 3-1 print `ADDI`).  `5 + 3 = 8` is
the primary write at `0x108`; the accumulator `0x104` receives 5 as the
interlocked instruction's second write, which is not a separate HRI
record.  C and V are unchanged (p. 3-6).
Source: p. 3-6, p. 1-7, Table 4-32 p. 4-3.
