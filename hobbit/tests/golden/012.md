# Golden 012 — `LDRAA` (absolute flow32 operand)

Image (8 bytes):

```text
80fa0000
01002c02
```

Reference pre-state as in 007.  `LDRAA *$0x100` is the three-parcel
monadic `opcode 0x00, subcode 0xA, smode 0xF`:
`0x8000|(0x00<<8)|(0xF<<4)|0xA = 0x80fa` (Table 1-19, p. 1-24; p. 3-31).
The 32-bit monadic operand is `(parcel2 << 16) | parcel3 =
0x00000100` (p. 1-23).  Mode 0xF is the flow32 absolute mode of
Table 1-23 (p. 1-26), which is the mode a JMP uses for its target.

p. 3-31: "The destination address is calculated as if a JMP instruction
was being executed and stored in the accumulator."  Table 1-23's mode
0xF `*$addr` already is the target address `0x00000100`; no memory word
is read.

L01. `HRI pc=0000 insn=80fa0000 sp=00000100>00000100 msp=00000180>00000180 we=1 addr=00000104 data=00000100 mask=0f trap=0 cyc=1`
Cycles: 1 — `LDRAA` is 1 in Table 4-32 (p. 4-3).  The accumulator is
the word at `CSP+4 = 0x104` (p. 1-7, Figure 1-4), and it receives
`0x100`.
Source: p. 3-31, p. 1-23, Table 1-19 p. 1-24, Table 4-32 p. 4-3.

L02. `HRI pc=0006 insn=2c020000 sp=00000100>00000100 msp=00000180>00000180 we=0 addr=00000000 data=00000000 mask=00 trap=0 cyc=1`
Cycles: 1 — `NOP` is 1 in Table 4-32 (p. 4-3).
Source: p. 3-35, Table 4-32 p. 4-3.
