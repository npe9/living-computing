# Golden 011 — `MOVA` (one-parcel stack-offset form)

Image (4 bytes):

```text
74822c02
```

Reference pre-state as in 007.  Table 1-15 (p. 1-22) gives `MOVA.SS`
opcode `0x1D`; the source field is stack offset 16 (field `16/4 = 4`)
and the destination is stack offset 8 (field `8/4 = 2`), so the parcel
is `(0x1D<<10)|(4<<5)|2 = 0x7482`.  p. 1-22: five-bit offsets are
multiplied by four before being added to SP.  The following `NOP` is
`0x2c02` (Table 1-17, p. 1-22).

p. 3-33: "The address of the source operand is calculated and stored in
the destination."  Source `R16` is `SP+16 = 0x00000110`; that address
is the stored value, not the word at it.

L01. `HRI pc=0000 insn=74820000 sp=00000100>00000100 msp=00000180>00000180 we=1 addr=00000108 data=00000110 mask=0f trap=0 cyc=1`
Cycles: 1 — `MOVA` is 1 in Table 4-32 (p. 4-3).  The destination is
`R8 = SP+8 = 0x108`; `&R16 = 0x110`.
Source: p. 3-33, Table 1-15 p. 1-22, Table 4-32 p. 4-3.

L02. `HRI pc=0002 insn=2c020000 sp=00000100>00000100 msp=00000180>00000180 we=0 addr=00000000 data=00000000 mask=00 trap=0 cyc=1`
Cycles: 1 — `NOP` is 1 in Table 4-32 (p. 4-3).
Source: p. 3-35, Table 4-32 p. 4-3.
