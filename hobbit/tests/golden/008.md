# Golden 008 — `DIV` with a negative dividend

Image (8 bytes):

```text
7322a7fd
00020008
```

Reference pre-state as in 007.  `MOV $-7,R8` is one parcel
`(0x1C<<10)|(0x19<<5)|2 = 0x7322`; `imm5` is sign-extended (p. 1-21), so
field `0x19` is `-7`, and the stack offset 8 is field 2 (p. 1-22).  The
`DIV $2,R8` parcel is `0x8000|(0x27<<8)|(0xF<<4)|0xD = 0xa7fd`
(Table 1-18, p. 1-24).

p. 3-17: "The destination operand is divided by the source operand, and
the quotient is placed in either the destination (DIV) or the
accumulator (DIV3).  Two's complement division is performed."  p. 1-28
defines `DIV a, b` as "divide b by a, signed".  The PRM prints no
rounding rule; this model takes the standard two's-complement
truncation toward zero (README choice 25), so `-7 / 2 = -3` with
remainder `-1`, not `-4`.

Cycles: 1 — `MOV` is 1 in Table 4-32 (p. 4-3); `-7 = 0xfffffff9`
stored at `SP+8`.
Source: p. 3-32, p. 1-21, Table 4-32 p. 4-3.

L02. `HRI pc=0002 insn=a7fd0002 sp=00000100>00000100 msp=00000180>00000180 we=1 addr=00000108 data=fffffffd mask=0f trap=0 cyc=38`
Cycles: 38 — Table 4-33 (p. 4-4) prints `DIV` as 38.  `-7 / 2 = -3 =
0xfffffffd`.  p. 3-17: the overflow bit is cleared in all cases except
`0x80000000 / 0xffffffff`, and the carry bit is unchanged; the
pre-state carry is 0, so both flags end 0.  Flags are state, not HRI
fields.
Source: p. 3-17, Table 1-18 p. 1-24, Table 4-33 p. 4-4.
