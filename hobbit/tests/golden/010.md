# Golden 010 — `TADD`, untagged and tagged

Image (16 bytes):

```text
70828cfd
00040008
8cfd0002
00082c02
```

Reference pre-state as in 007.  `MOV $4,R8` is
`(0x1C<<10)|(4<<5)|2 = 0x7082`.  `TADD $4,R8` is
`0x8000|(0x0C<<8)|(0xF<<4)|0xD = 0x8cfd` with source field `0x0004` and
destination field `0x0008` (Table 1-18, p. 1-24; p. 3-44).  The second
`TADD $2,R8` at byte 8 has the same parcel and source field `0x0002`.
The final `NOP` is the one-parcel `0x2c02` (Table 1-17, p. 1-22).

p. 3-44:

```text
if ((src[1:0] != 0x0) || (dst[1:0] != 0x0))
    PSW.F = 1
else {
    dst + src
    "unsigned overflow" ? PSW.C = 1 : PSW.C = 0
    "signed overflow" ? PSW.V = 1 : PSW.V = 0
    PSW.F = PSW.V
}
if (PSW.F = 0)
    dst = dst + src
```

so a tagged operand sets F and leaves C/V as they were, and an untagged
operand whose sum does not overflow stores the sum and leaves F=0.
