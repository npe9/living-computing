# Golden 022 — `ORI` and `ANDI`: the accumulator write, and R4 as the destination

Image (20 bytes):

```text
70a281fd
00030008
60237121
82fd0006
00046023
```

Pre-state as in the README (SP `0x100`, MSP `0x180`, PSW `0x200`): every
stack word used here is inside the cache window.

Golden 009 pins the interlocked `ADDI`'s primary write only; the
accumulator save it describes is a second architectural write the fixed
line cannot show (README choice 26).  This golden makes that second write
visible: each interlocked instruction is followed by `MOV R4, R12`, which
copies the accumulator into a word whose store *is* on a line.  It also
pins the p. 3-6/3-8/3-37 note "If R4 is the destination, after the
interlocked instruction completes, R4 is the previous value of R4; hence,
no operation is performed."

It was written for the s9term boot on the core (docs/p9boot.md, "The boot
on the core"): the kernel's `tas` is `ORI $1, *lock`, and at record
126,600 of the boot the core, which did not implement the interlocked
forms, took the unimplemented-instruction trap instead
(docs/conformance_1to1.md §1d, finding 1).

Encodings (Tables 1-15 p. 1-22, 1-18 p. 1-24, 1-21 p. 1-25):

- `MOV $5, R8` = `(0x1C<<10)|(5<<5)|2` = `0x70a2` (`MOV.IS`, as golden 009).
- `ORI $3, R8` = `0x8000|(0x01<<8)|(0xF<<4)|0xD` = `0x81fd`, source field
  `0x0003` (mode `0xF`, `$data`), destination field `0x0008` (mode `0xD`,
  `Roffset:W`): opcode `0x01`, "length 6, gen16, gen16" (p. 3-37).
- `MOV R4, R12` = `(0x18<<10)|(1<<5)|3` = `0x6023` (`MOV.SS`, `stk5` = 1
  and 3; Table 1-15 p. 1-22, as golden 001's `MOV R4, R8` = `0x6022`).
- `MOV $9, R4` = `(0x1C<<10)|(9<<5)|1` = `0x7121`.
- `ANDI $6, R4` = `0x8000|(0x02<<8)|(0xF<<4)|0xD` = `0x82fd`, fields
  `0x0006` and `0x0004`: opcode `0x02` (p. 3-8).

The operation, p. 3-37 (ORI) and p. 3-8 (ANDI):

```text
hidden = dst
dst |= src          (ANDI: dst &= src)
Acc = hidden
```

"The original value of dst is placed in the accumulator"; the accumulator
is the word at `CSP+4` (p. 1-7, Figure 1-4), here `0x104`.

Cycle numbers: Table 4-32 (p. 4-3) prints `ORI` and `ANDI` as 2 and `MOV`
as 1.  The Notes (pp. 3-8, 3-37) say the pipeline is cleared before an
interlocked instruction enters it and no other instruction enters until it
completes, but Chapter 4 prints no row for that wait; under the p. 4-1
assumptions no number is invented for it, so each `MOV` is its printed 1.

L01. `HRI pc=0000 insn=70a20000 sp=00000100>00000100 msp=00000180>00000180 we=1 addr=00000108 data=00000005 mask=0f trap=0 cyc=1`
Cycles: 1 — `MOV` is 1 in Table 4-32 (p. 4-3).
`*(SP+8) = 5`.
Source: p. 3-32, Table 4-32 p. 4-3.

L02. `HRI pc=0002 insn=81fd0003 sp=00000100>00000100 msp=00000180>00000180 we=1 addr=00000108 data=00000007 mask=0f trap=0 cyc=2`
Cycles: 2 — `ORI` is 2 in Table 4-32 (p. 4-3).
`hidden = 5`, `dst = 5 | 3 = 7` (the line's write, `0x108`), `Acc = 5`
(the second write, `0x104`, not on a line).  C and V are not affected.
Source: p. 3-37, p. 1-7, Table 4-32 p. 4-3.

L03. `HRI pc=0008 insn=60230000 sp=00000100>00000100 msp=00000180>00000180 we=1 addr=0000010c data=00000005 mask=0f trap=0 cyc=1`
Cycles: 1 — `MOV` is 1 in Table 4-32 (p. 4-3); no printed row for the
interlocked wait (see above).
`*(SP+12) = *(SP+4)`: the 5 the `ORI` left in the accumulator.  A model
that drops the accumulator write stores whatever `0x104` held before
(0 here, the zero-filled cache).
Source: p. 3-32, p. 3-37, Table 4-32 p. 4-3.

L04. `HRI pc=000a insn=71210000 sp=00000100>00000100 msp=00000180>00000180 we=1 addr=00000104 data=00000009 mask=0f trap=0 cyc=1`
Cycles: 1 — `MOV` is 1 in Table 4-32 (p. 4-3).
`*(SP+4) = 9`: the accumulator itself.
Source: p. 3-32, Table 4-32 p. 4-3.

L05. `HRI pc=000c insn=82fd0006 sp=00000100>00000100 msp=00000180>00000180 we=1 addr=00000104 data=00000009 mask=0f trap=0 cyc=2`
Cycles: 2 — `ANDI` is 2 in Table 4-32 (p. 4-3).
The destination is R4, the accumulator: `hidden = 9`, `dst = 9 & 6 = 0`,
then `Acc = hidden = 9`.  "If R4 is the destination, after the interlocked
instruction completes, R4 is the previous value of R4; hence, no operation
is performed" (p. 3-8 Notes): the word's final value is 9, and that is the
one write the line carries.
Source: p. 3-8, p. 1-7, Table 4-32 p. 4-3.

L06. `HRI pc=0012 insn=60230000 sp=00000100>00000100 msp=00000180>00000180 we=1 addr=0000010c data=00000009 mask=0f trap=0 cyc=1`
Cycles: 1 — `MOV` is 1 in Table 4-32 (p. 4-3).
`*(SP+12) = *(SP+4) = 9`.  A model that stores `9 & 6` into R4 stores 0
here.
Source: p. 3-32, p. 3-8, Table 4-32 p. 4-3.
