# Hewlett-Packard 9810

The HP 9810 was part of Hewlett-Packard's second-generation programmable
calculator family. It moved calculator functions into a microprogrammed
architecture based on a compact minicomputer-like instruction set, with
dedicated arithmetic and I/O support.

Bluespec implementation: bsv/ (not started).

See [`plan.md`](plan.md) and [`docs/README.md`](docs/README.md). The initial
source is Chapter 49, printed p. 801, of *Computer Structures: Principles and
Examples* (1982).
