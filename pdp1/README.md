# DEC PDP-1 (1959)

Ben Gurley, DEC. First minicomputer / interactive machine. 18-bit words, 4K words core, 5 μs cycle, CRT display, Spacewar!. Lineage: TX-0 → PDP-1 → PDP-4/7/9/15.

Bluespec implementation: `bsv/` (not started).

See [`plan.md`](plan.md) for the staged reproduction plan and
[`docs/README.md`](docs/README.md) for the local primary-source inventory.

Sources: *PDP-1 Handbook* (F-15, 1961).
