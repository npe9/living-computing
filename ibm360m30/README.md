# IBM System/360 Model 30

The System/360 Model 30 was a lower-cost implementation of the common
System/360 architecture. Its control was microprogrammed: 60-bit
microinstructions in card-capacitor read-only storage controlled storage,
register transfers, the ALU, sequencing, and status functions.

Bluespec implementation: bsv/ (not started).

See [`plan.md`](plan.md) and [`docs/README.md`](docs/README.md). The initial
source is Chapter 12 of *Computer Structures: Principles and Examples* (1982).
