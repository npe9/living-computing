# Experimental Ethernet

The experimental Ethernet was a distributed local network using a passive
branching coaxial bus. Stations broadcast variable-length packets, listen for
traffic, and accept packets addressed to them; repeaters, filters, and
gateways extend the network. Distributed control avoids a central switching
bottleneck.

Bluespec implementation: bsv/ (not started).

See [`plan.md`](plan.md) and [`docs/README.md`](docs/README.md). The initial
source is Chapter 26, printed p. 429, of *Computer Structures: Principles and
Examples* (1982).
