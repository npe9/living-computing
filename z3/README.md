# Zuse Z3 (1941)

Konrad Zuse, Berlin. First working programmable, fully automatic digital computer. Electromechanical (2,600 relays), binary floating point (22-bit: 1 sign, 7 exponent, 14 mantissa), 64-word memory, program on punched 35mm film. No conditional branch.

Bluespec implementation: `bsv/` (not started).

Sources: Zuse, *Der Computer – Mein Lebenswerk*; Rojas, "How to Make Zuse's Z3 a Universal Computer" (IEEE Annals 1998).
