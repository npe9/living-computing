# IBM System/360 (1964)

Amdahl, Blaauw, Brooks. First computer *family* with a common architecture across implementations (the "architecture" vs "implementation" distinction). 32-bit words, 8-bit bytes, 16 general registers, 24-bit addressing, hexadecimal floating point, microprogrammed low-end models, channels. Lineage runs unbroken to z/Architecture.

Bluespec implementation: `bsv/` (not started).
