# UNIVAC I (1951)

Eckert–Mauchly / Remington Rand. First commercial computer in the US. Decimal, 12-character words (excess-3 BCD), 1000-word mercury delay-line store, magnetic-tape I/O (UNISERVO), serial arithmetic, ~5,200 valves.

Bluespec implementation: `bsv/` (not started).

Sources: *UNIVAC I Programming Manual* (Remington Rand, 1954).
