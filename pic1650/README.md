# General Instrument PIC1650

The PIC1650 was a monolithic microcomputer integrating processor, memory, and
I/O functions for embedded control. Its architecture demonstrates the
tradeoff between a compact application-specific instruction set and the
flexibility of a general microprocessor.

Bluespec implementation: bsv/ (not started).

See [`plan.md`](plan.md) and [`docs/README.md`](docs/README.md). The initial
source is Chapter 35, printed p. 602, of *Computer Structures: Principles and
Examples* (1982).
