# Manchester Baby / SSEM (1948)

Williams, Kilburn, Tootill, Manchester. First stored-program computer to run a program (21 June 1948). 32 words × 32 bits Williams-tube store, 7 instructions, serial arithmetic, single accumulator. Built to test the Williams–Kilburn tube.

Bluespec implementation: `bsv/` (not started).

Sources: Lavington, *Early British Computers*; Kilburn's 1948 report; Napper's SSEM reference.
