# Tandem 16 NonStop

The Tandem 16 NonStop was a commercially available fault-tolerant system
organized from processor modules, dual-ported I/O controllers, a dual
interprocessor bus, and redundant power distribution. It was designed to
continue operation through a single failure and support online repair.

Bluespec implementation: bsv/ (not started).

See [`plan.md`](plan.md) and [`docs/README.md`](docs/README.md). The initial
source is Chapter 29, printed p. 470, of *Computer Structures: Principles and
Examples* (1982).
