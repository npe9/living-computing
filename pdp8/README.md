# DEC PDP-8 (1965)

Edson de Castro / Gordon Bell, DEC. The first commercially successful minicomputer (~50,000 built). 12-bit words, 4K words core, 8 basic instructions, single accumulator + link, page-relative addressing. Long-lived lineage (PDP-8/I, /E, /A, Intersil 6100 on a chip).

Bluespec implementation: `bsv/` (not started).

See [`plan.md`](plan.md) for the staged reproduction plan and
[`docs/README.md`](docs/README.md) for the local primary-source inventory.

Sources: *PDP-8 Small Computer Handbook* (DEC, 1966 onward).
