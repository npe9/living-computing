# Whirlwind I (1951)

Jay Forrester, MIT. First real-time computer and first to use magnetic-core memory (1953). 16-bit parallel words, 2048 words, ~5,000 valves, bit-parallel arithmetic — the design lineage of SAGE, TX-0/TX-2 and the DEC PDP series.

Bluespec implementation: `bsv/` (not started).

See [`plan.md`](plan.md) for the staged reproduction plan and
[`docs/README.md`](docs/README.md) for the local primary-source inventory.

Sources: *Whirlwind I Computer: Programming Manual*; Redmond & Smith, *Project Whirlwind*.
