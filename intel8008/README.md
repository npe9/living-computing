# Intel 8008

The Intel 8008 was an early 8-bit microprocessor whose small instruction set,
register organization, and external support logic made processor technology
available for embedded and control systems. The book places it at the start
of the 8008-to-8086 microprocessor evolution.

Bluespec implementation: bsv/ (not started).

See [`plan.md`](plan.md) and [`docs/README.md`](docs/README.md). The initial
source is Chapter 37, printed p. 615, of *Computer Structures: Principles and
Examples* (1982).
