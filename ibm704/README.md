# IBM 704 (1954)

Gene Amdahl et al. First mass-produced computer with hardware floating point and core memory. 36-bit words, 3 index registers, 4K–32K words. Home of FORTRAN and LISP. Instruction set continued in 709/7090/7094.

Bluespec implementation: `bsv/` (not started).

Sources: *IBM 704 Electronic Data-Processing Machine Manual of Operation* (Form 24-6661).
