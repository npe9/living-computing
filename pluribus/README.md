# Pluribus fault-tolerant multiprocessor

Pluribus was a modular multiprocessor developed for ARPANET interface
processing and other continuously operating services. It used spare and
replaceable modules, parity and checking, and software-directed isolation and
recovery so that availability mattered more than complete fault elimination.

Bluespec implementation: bsv/ (not started).

See [`plan.md`](plan.md) and [`docs/README.md`](docs/README.md). The initial
source is Chapter 23 of *Computer Structures: Principles and Examples* (1982).
