# STAR fault-tolerant computer

The STAR computer was a fault-tolerant system built from checked functional
units, redundant resources, residue checking, and automatic maintenance
techniques. Its design was also adapted for spacecraft control, where repair
and unattended operation imposed strict weight, power, and reliability
constraints.

Bluespec implementation: bsv/ (not started).

See [`plan.md`](plan.md) and [`docs/README.md`](docs/README.md). The initial
source is Chapter 27 of *Computer Structures: Principles and Examples* (1982).
