# Colossus (1944)

Tommy Flowers, Bletchley Park. First programmable electronic digital computer (1,600–2,400 valves). Special purpose: Lorenz SZ40/42 cipher-wheel setting. Not stored-program; configured with plugs and switches; paper-tape driven at 5,000 chars/s.

Bluespec implementation: `bsv/` (not started).

Sources: Copeland (ed.), *Colossus: The Secrets of Bletchley Park's Codebreaking Computers*; General Report on Tunny (1945).
